LMU 실시간 연결

LMU를 실행하고 차에 탄 뒤 스포터나 피트월을 켜세요. 실시간 연결은 자동입니다. 별도 연결 파일이나 개발 도구를 받거나 만들 필요가 없습니다.

주행 코치 2.0.3 이상실시간 연결은 인터넷 없이 사용

1LMU를 고르세요

실행.bat으로 앱을 켜고 상단에서 LMU를 고릅니다. 게임을 실행하고 차에 탑니다.

iRacing과 LMU에서 같은 스포터·피트월·F8 질문·오버레이를 사용합니다.

localhost:24157

게임에서 차에 타세요.

2스포터나 피트월을 켜세요

앱의 음성 코치에서 필요한 안내를 켭니다. 설치된 LMU의 데이터 구조를 앱이 읽어 맞춥니다.

일반적인 데이터 구조 변경은 자동으로 따릅니다. 연결 방식 자체가 달라지면 앱 업데이트가 필요합니다.

3상태가 궁금하면 설정에서 확인하세요

설정 → LMU 실시간 연결에 준비 상태나 실패 이유가 나옵니다. 앱 업데이트가 필요하다고 나오면 설정 → 업데이트에서 새 버전을 확인하세요.

“준비됨”은 설치된 LMU 파일과 리더를 확인했다는 뜻입니다. 실제 주행 데이터는 LMU에서 차에 탄 뒤 들어옵니다.

앱 업데이트 필요LMU가 연결 방식을 바꿨습니다. 설정 → 업데이트에서 앱을 업데이트하세요.
연결 구성 파일 확인 실패앱을 다시 설치하세요. 직접 빌드나 개발 도구 설치는 필요하지 않습니다.
LMU 설치 확인 필요Steam에서 LMU 설치와 게임 파일 무결성을 확인한 뒤 앱을 다시 실행하세요. 다른 Steam 라이브러리도 자동으로 찾습니다.

LMU 패치마다 앱을 업데이트해야 하나요?

일반적인 데이터 구조 변경은 설치된 LMU 파일을 읽어 자동으로 따릅니다. 따로 할 일은 없습니다.

연결 방식이나 필드의 의미가 달라져 지원할 수 없으면 앱 업데이트가 필요합니다. 지원되지 않는 데이터를 추측해 읽지는 않습니다.

Google 키와 마이크 권한은 F8 음성 질문을 쓸 때 별도로 필요합니다.
