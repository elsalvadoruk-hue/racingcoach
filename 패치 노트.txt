■ LMU 지원 (개발 중, 아직 배포 전)

- LMU 지도에서 위성 버튼과 위성 배경 요청을 제거했습니다. 주행선과 고스트는 개략도에서 확인합니다.
- 주행 선택 창에서 다운로드한 DuckDB를 Windows 파일 선택 창으로 엽니다. 주행 파일과 기준 파일 양쪽에서 가능합니다.
  원본을 보존하고 앱에 복사본을 저장하며, 같은 차량·트랙·레이아웃의 기준 랩을 골라 비교합니다. 날씨 미상은 확인 필요로 표시합니다.
- LMU 사용 가이드를 목차·검색·16개 장으로 정리했습니다. 첫 장에서 iRacing과 다른 점과 기능별 지원을 확인합니다.
  연결 문제 해결, 게임별 설정, 차량별 오버레이 저장을 설명합니다. 버추얼 에너지 안내는 단위 확인 후 켜지는 준비 중 기능으로 표시합니다.
- LMU를 고르면 공식 사이트의 파랑을 부드럽게 조정한 네이비·회청색 테마로 표시합니다.
  배경은 검정보다 파란 기운을 살리고 버튼·선택·포커스는 차분한 파랑으로 표시합니다. 그래프의 내 랩은 파랑, 기준 랩은 모래색입니다.
  제동·가속·손실/이득 색은 의미를 유지합니다. iRacing 화면과 게임 위 오버레이 HUD 색은 유지합니다.
- 오버레이 위치·크기·불투명도·고정 상태를 게임과 차량별로 기억합니다. 주행 중 자동 표시는 게임별로 기억합니다.
  설정에 적용 대상을 표시하고 해당 차량 설정만 지워 게임 기본값으로 돌아갈 수 있습니다. 기존 설정 파일은 보존합니다.
- 스포터·피트월·음성 속도와 볼륨·입출력 장치·무전 효과·화면 도움말·그래프 순서·지도 색·연습 기준을 게임별로 기억합니다.
  설정 화면은 선택한 게임의 값을 바꾸고 실제 주행에는 연결된 게임의 값을 적용합니다. 기존 저장값은 두 게임의 시작값으로 보존합니다.
- LMU 셋업 실험은 준비 중입니다. 셋업 메뉴에서는 추후 공개 안내와 주행 요약으로 가는 버튼을 보여 줍니다.
  iRacing 셋업 실험은 기존과 같습니다.
- 상단에서 LMU를 고르면 LMU 주행 기록(DuckDB)을 iRacing과 같은 분석으로 봅니다.
  오늘의 연습 과제(코너별 원인과 바꿀 조작), 코너 비교, 랩 분석, 전문가 보기, 코너 번호, 연습 시작·다음 주행 평가가 iRacing과 같습니다.
  몬차·르망·스파·이몰라·포르티망·세브링·COTA·인터라고스·후지·실버스톤은 iRacing 공식 지도로 코너 번호를 자동 제안합니다.
  LMU 기록 좌표는 실제 지도와 맞지 않아 지도는 위성 배경 없이 개략도로 그립니다.
- 음성 코치(스포터·피트월·포메이션 브리핑·F8 질문)와 오버레이는 iRacing과 같은 기능을 씁니다.
  LMU를 실행하고 차에 타면 자동으로 LMU에 연결됩니다. 처음 한 번은 설정 → LMU 실시간 연결에서 브리지를 빌드합니다.
  좌우 스포터는 주변 차 좌표로 겹침을 계산합니다(차량 크기는 공통 근사값).
- LMU가 공개하지 않는 값(급유 설정량, 수리 시간, 인시던트 점수, Garage61 기준)에 기대는 안내는 나오지 않습니다.
- 다른 Steam 라이브러리 폴더에 설치한 LMU도 자동으로 찾습니다.
- iRacing·LMU 모두 비교 기준으로 조건이 비슷한 내 베스트 랩을 다른 주행 기록에서도 자동으로 찾습니다.
- 확정한 코너 번호가 코너 비교 화면의 구간 이름에도 바로 표시됩니다(iRacing 포함).

■ 1.4.0 (2026-10-19)

[중요] 기존 사용자는 음성 폴더 두 개를 지우고 전체 음성팩 1.4.0을 새로 넣으세요.
  랩타임과 SOF 안내가 음성 조각(OGG)을 이어 말하는 방식으로 바뀌어,
  예전 랩타임 통문장 MP3 약 1.4GB를 더 이상 쓰지 않습니다. 새 전체 음성팩은 약 0.6GB입니다.
  이번 버전은 이전 버전에서 오는 음성 업데이트팩을 내지 않습니다.

  1. 앱과 실행.bat 창을 모두 닫습니다.
  2. 프로그램을 업데이트하고(GitHub Code → Download ZIP 덮어쓰기) 설치.bat을 다시 실행합니다.
     soundfile 패키지가 새로 필요합니다.
  3. 데이터 폴더에서 아래 두 폴더만 지웁니다.
       프로그램 폴더\data\radio_audio
       프로그램 폴더\data\spotter_audio
     데이터 폴더를 따로 지정했다면 설정 → 설치 설정에 표시된 데이터 폴더 안의 같은 이름 폴더입니다.
  4. 전체 음성팩 1.4.0(Google Drive 공유 폴더)을 실행.bat이 있는 프로그램 폴더에 풉니다.
     data\radio_audio(안에 pieces 폴더 포함)와 data\spotter_audio가 다시 생기면 됩니다.
  5. 실행.bat으로 다시 시작합니다.

  지우면 안 되는 것: data 폴더 자체와 그 안의 나머지 파일 전부
  (주행 기록 DB, settings.json, Google 키, Garage61 토큰, 코너 번호, 피트 기록, 경기 기록 등).
  음성팩을 새로 넣지 않으면 랩타임·SOF 안내가 나오지 않습니다(Google 키가 있으면 처음 쓰일 때 합성합니다).

새 기능
- 포메이션 랩 두 번째 안내에서 SOF(그리드 실력)와 레이팅 목표를 말합니다.
  예: "이번 경기 SOF는 약 2300입니다." "아이레이팅 순위는 클래스 7위입니다." "클래스 9위 안에 들면 레이팅이 오릅니다."
  모든 차가 움직인 뒤에 계산하고 접속하지 않은 차는 뺍니다(그리드에서는 숫자가 맞지 않았음).
  SOF는 iRacing과 같은 식으로 계산해 100 단위로 반올림하고, 클래스가 여럿이면 내 클래스 기준입니다.
  레이팅 목표는 참가자별 이길 확률로 구한 추정입니다. iRating을 모르면(AI 경기 등) 말하지 않습니다.
  숫자는 문장 속에서 잘라 낸 음성 조각(앞말 · 천 단위 · 백 단위)을 이어 말합니다. "약" 뒤에 짧게 쉽니다.
  값마다 문장을 따로 만들지 않아 100~10000 전체가 조각 34개(약 1.4MB)로 됩니다.
  조각은 data/radio_audio/pieces/에 OGG(Opus)로 저장되며 음성 미리 받기와 음성팩에 함께 들어갑니다.
- 랩타임 안내도 조각을 이어 말합니다. 앞부분("이번 랩 1분")과 뒷부분("42초 3입니다.")을 따로 받아 둡니다.
  초가 한 자리면 분부터 한 조각("1분 5초 0입니다.")으로 써서 숫자가 늘어지지 않습니다.
  조각마다 음성 인식으로 되읽어 글자와 맞는지, 음높이와 빠르기가 평소와 같은지 확인한 것만 씁니다.
  스포터 목소리당 랩타임 음성이 약 3만 5천 개에서 3,700개 조각으로 줄었습니다.
  조각은 OGG(Opus, 약 37kbps)로 압축해 둡니다. 4개 목소리를 합쳐 약 0.1GB입니다(예전 통문장 MP3는 1.38GB).
  음성 전체가 약 1.9GB에서 0.6GB로 줄었습니다. 예전 통문장 MP3는 음성팩에 넣지 않습니다(위 중요 안내).
