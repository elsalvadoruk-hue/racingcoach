■ 2.3.0 (2026-10-25)

Voice Studio에서 만든 커스텀 음성팩을 설치해 사용할 수 있으며 오버레이 설정·코칭 표시를 개선했습니다.
새 기본 음성 없음. 기존 기본 음성팩 2.2.0을 그대로 사용합니다. 커스텀 음성팩과 별도 제작 프로그램 Voice Studio는 앱 설치본에 포함되지 않습니다.

[앱 전체]
- 음성 코치에 '음성팩 설치·관리'를 추가했습니다. .rcvoice.zip 파일이나 팩 폴더를 검사해 앱의 관리 폴더에 설치하고, 설치 목록·역할별 문장 수·버전·미리듣기를 확인합니다. 설치와 미리듣기만으로 사용 중인 목소리가 바뀌지는 않습니다.
- 음성팩 설치의 전송·음성 검사·파일 복사·최종 확인 단계와 실제 처리 개수·경과 시간을 표시합니다. 전송 100% 이후에도 검증이 이어짐을 안내하고, 새로고침 후 진행 중인 작업 복원·오류 확인·재시도를 지원합니다. 스포터·피트월 목소리를 바꿀 때도 선택칸 밖에 적용 상태와 파일 확인 개수를 표시해 기다리는 이유를 알 수 있습니다.
- 원하는 역할만 담은 부분팩을 설치할 수 있습니다. 기존 WAV 팩과 Ogg Opus 팩을 지원하며, Opus는 실제 디코딩까지 검사합니다. 제작할 때의 원본 WAV는 보존합니다.
- '적용만 해제·파일 보관'과 '설치 파일까지 삭제'를 구분했습니다. 적용을 해제하면 두 게임의 해당 팩 선택을 정리하고 기본 목소리로 돌아갑니다. 파일 삭제는 앱이 관리하는 설치 사본에만 적용하며 받은 원본 ZIP·폴더와 Studio 프로젝트는 보존합니다.
- 앱 업데이트로 새 안내 문장이 추가되면 설치팩에 추가 제작 알림을 표시합니다. '추가 제작 목록 저장'으로 JSON을 받아 Studio에서 새 대본만 이어 만들 수 있습니다. 제작 당시 전체 목록과 비교하며, 처음부터 만들지 않았던 문장을 업데이트 신규분으로 세지 않습니다. 비교 정보가 없는 구형 팩은 신규 문장을 자동 판정하지 않습니다.
- 별도 프로그램 Voice Studio에서 앱 목록 읽기 → 대본·말투 선택 → 모델·화자 선택 → 시험 생성·검수 → 전체 제작 → 팩 저장으로 이어집니다. ChatGPT에 보낼 대본·검수 자료와 수정 JSON의 전후 비교·선택 적용을 지원합니다. 자료는 사용자가 직접 전달합니다.
- Voice Studio는 작업·검수·메모를 저장하고, 누락 음성 이어 만들기와 프로젝트 휴지통·복원을 지원합니다. 개인 제작설정을 저장해 같은 목소리로 추가 제작할 수 있으며, 추가 제작 목록을 넣어도 기존 음성·검수·목소리 설정은 유지합니다. 로컬 경로가 포함된 개인 제작설정은 공개 음성팩에 넣지 않습니다.

[iRacing·LMU 공통]
- 스포터·주행 코치·레이스 엔지니어·전략 엔지니어의 목소리를 게임별로 각각 선택합니다. 기본 목소리와 커스텀팩을 역할별로 섞을 수 있고, 해당 역할이 있는 팩만 선택 목록에 표시합니다. 스포터·자동 보고가 켜져 있을 때는 목소리 변경을 잠급니다.
- 선택한 팩에 없는 문장은 이미 준비된 기본 음성·숫자 조각으로 보완합니다. 양쪽 모두 없으면 해당 안내를 생략하고, 커스텀 음성 누락 때문에 유료 합성을 자동 요청하지 않습니다. 필수 스포터 호출이 양쪽 모두에 없으면 켜기 전에 준비할 항목을 안내합니다. AI 자유 답변의 음성과는 별도입니다.
- 왼쪽에 오버레이 설정 메뉴를 추가했습니다. 연습·퀄리·레이스·포메이션마다 코칭 카드 또는 입력값 그래프를 고르고 게임 기본값·현재 차량별로 저장합니다. 기존 자동 표시·위치·크기·불투명도·고정 설정은 '창·표시 설정 → 설정 열기'에서 조절합니다.
- 코칭 카드의 표시 항목을 여러 개 체크할 수 있습니다. 상황과 실제 측정 자료에 맞춰 큰 정보 1개와 보조 최대 2개를 선택합니다. 직접 고른 항목과 모두 해제한 설정을 유지하며, 이전 영역별 설정도 선택 목록으로 읽어들입니다.
- 과제·비교 기록·코너 분석 없이 쓰는 '자동 주행 코칭'을 기본 추천에 추가했습니다. 정상 주행 약 1초 뒤부터 최근 10초의 무입력·동시 입력 시간과 제동 해제 → 가속 연결 시간을 관측하고 여유 있는 직선에서 표시합니다. 피트·리플레이·저속·옐로·근접·입력 공백을 제외하고 포메이션은 그린 후 관측합니다. 관측값을 실수나 시간 손실의 원인으로 단정하지 않습니다.
- 연습 목표·성공률은 원하는 경우에만 과제를 연결해 사용합니다. 실제 게임 입력·코너 구간·비교 기준·목표 준비 상태와 '내용 표시 방법'을 추가해 17개 항목의 준비 조건·표시 시점을 확인할 수 있습니다. 코너별 비교에는 같은 차량·트랙 파일을 분석해 준비한 구간을 사용합니다.
- 연속 코너에서는 결과를 모으고 다음 직선에서 관측된 양의 시간 차이가 가장 큰 코너를 우선 표시합니다. 수치는 6초간 고정하고 새 내용은 최소 8초 간격으로 보여줍니다. 알려진 다음 제동까지 여유가 짧거나 실제 제동·회전·근접 상황이면 상세 내용을 접습니다. 예측 자료가 없는 첫 주행은 실제 입력이 2초간 안정된 뒤 표시하며, '랩 종료 후' 선택도 지원합니다.
- 기준과 처음 달라진 조작 위치, 재리프트·재제동 반복, 진입·회전·탈출 시간 차이, 빠른 통과의 공통 패턴, 접촉·손상 신호 전후 관측 변화를 코칭 카드에서 선택할 수 있습니다. 반복 패턴은 깨끗한 통과 3회, 공통 패턴은 비슷한 조건 5회, 접촉 전후는 이전 2랩과 이후 1랩이 필요합니다. 부족한 자료는 측정 대기로 표시하며 원인·부품 손상·셋업 효과를 확정하지 않습니다.
- 오버레이 제목·수치·단위 설명을 키우고 창 전체 폭을 활용합니다. 비교 결과 옆에 기준 랩타임과 기준보다 빠름·느림을 크게 표시하며, 기존 급유 등 하단 알림도 유지합니다.
- 앱의 오버레이 미리보기를 실제 Windows 오버레이와 같은 그리기 코드로 바꿨습니다. 입력 그래프·페달 막대·기어·코칭 카드의 배치·글꼴과 창 크기·글자 크기·표시/배경 불투명도를 반영합니다. 크게 보기·네 세션 비교에서도 같은 화면을 사용하고 좁은 공간에서는 비율을 유지해 축소합니다. 표시 수치는 샘플입니다.

[중요] 기존 사용자는 음성 폴더 두 개를 지우고 전체 음성팩 1.4.0을 새로 넣으세요.

  1. 앱과 실행.bat 창을 모두 닫습니다.
  2. 프로그램을 업데이트하고(GitHub Code → Download ZIP 덮어쓰기) 설치.bat을 다시 실행합니다.

  3. 데이터 폴더에서 아래 두 폴더만 지웁니다.
       프로그램 폴더\data\radio_audio
       프로그램 폴더\data\spotter_audio
     데이터 폴더를 따로 지정했다면 설정 → 설치 설정에 표시된 데이터 폴더 안의 같은 이름 폴더입니다.

     data\radio_audio(안에 pieces 폴더 포함)와 data\spotter_audio가 다시 생기면 됩니다.
  5. 실행.bat으로 다시 시작합니다.

  지우면 안 되는 것: data 폴더 자체와 그 안의 나머지 파일 전부
  (주행 기록 DB, settings.json, Google 키, Garage61 토큰, 코너 번호, 피트 기록, 경기 기록 등).
  음성팩을 새로 넣지 않으면 랩타임·SOF 안내가 나오지 않습니다(Google 키가 있으면 처음 쓰일 때 합성합니다).

새 기능
- 포메이션 랩 두 번째 안내에서 SOF(그리드 실력)와 레이팅 목표를 말합니다.
  예: "이번 경기 SOF는 약 2300입니다." "아이레이팅 순위는 클래스 7위입니다." "클래스 9위 안에 들면 레이팅이 오릅니다."
  모든 차가 움직인 뒤에 계산하고 접속하지 않은 차는 뺍니다(그리드에서는 숫자가 맞지 않았음).
  SOF는 iRacing과 같은 식으로 계산해 100 단위로 반올림하고, 클래스가 여럿이면 내 클래스 기준입니다.
  레이팅 목표는 참가자별 이길 확률로 구한 추정입니다. iRating을 모르면(AI 경기 등) 말하지 않습니다.
  숫자는 문장 속에서 잘라 낸 음성 조각(앞말 · 천 단위 · 백 단위)을 이어 말합니다. "약" 뒤에 짧게 쉽니다.
  값마다 문장을 따로 만들지 않아 100~10000 전체가 조각 34개(약 1.4MB)로 됩니다.
  조각은 data/radio_audio/pieces/에 OGG(Opus)로 저장되며 음성 미리 받기와 음성팩에 함께 들어갑니다.
- 랩타임 안내도 조각을 이어 말합니다. 앞부분("이번 랩 1분")과 뒷부분("42초 3입니다.")을 따로 받아 둡니다.
  초가 한 자리면 분부터 한 조각("1분 5초 0입니다.")으로 써서 숫자가 늘어지지 않습니다.
  조각마다 음성 인식으로 되읽어 글자와 맞는지, 음높이와 빠르기가 평소와 같은지 확인한 것만 씁니다.
  스포터 목소리당 랩타임 음성이 약 3만 5천 개에서 3,700개 조각으로 줄었습니다.
  조각은 OGG(Opus, 약 37kbps)로 압축해 둡니다. 4개 목소리를 합쳐 약 0.1GB입니다(예전 통문장 MP3는 1.38GB).
  음성 전체가 약 1.9GB에서 0.6GB로 줄었습니다. 예전 통문장 MP3는 음성팩에 넣지 않습니다(위 중요 안내).
