# iRacing 주행 코치

내 iRacing IBT와 Garage61 기준 랩을 비교하고, 주행 중 한국어 스포터·피트월을 제공하는 Windows용 로컬 앱입니다.

**현재 버전: 1.3.1** · [최신 릴리즈](../../releases/latest) · [버전별 변경 내역](../../releases) · [그림 매뉴얼](manual/매뉴얼.html) · [PDF 매뉴얼](manual/매뉴얼-1.3.0.pdf)

**음성 다운로드: [Google Drive 공유 폴더](https://drive.google.com/drive/folders/1MPvrKi4Zw9fInU5f84mCwe_Bt0uhW631?usp=sharing)** — 프로그램은 GitHub **Code → Download ZIP**, 음성은 이 폴더에서 받으세요.

**1.3.1: Bluetooth 출력장치 복구** — 음성 파일은 1.3.0과 같습니다. 기존 음성이 있으면 다시 받지 않아도 됩니다. 처음 설치하거나 음성이 누락됐으면 1.3.0 전체 음성팩을 받으세요.

**이용조건: 개인·비상업적 사용 무료 / 무단 재배포·판매 금지** — 프로그램과 공식 음성팩의 자세한 조건은 [이용조건](LICENSE.md)을 확인하세요.

## 주요 기능

- **주행 분석:** 랩·코너 비교, 지도·고스트·조작 그래프, Garage61 기준 선택.
- **주행 지원:** 한국어 스포터, 레이스·전략 엔지니어 자동 보고, F8 음성 질문.
- **연습과 셋업:** 오늘의 한 가지, 구간 반복 연습, 단일 변경 A/B 실험과 기록.

상세 사용법과 문제 해결은 앱 왼쪽 아래 **사용 가이드** 또는 매뉴얼을 확인하세요. 버전별 변경 설명은 **Releases**에서 관리하며, 기존 [패치 노트](패치%20노트.txt)는 오프라인 기록으로 유지합니다.

## 설치와 실행

1. Python 3.10 이상(**3.12 권장**)과 **Node.js LTS**를 설치합니다.
2. 이 저장소의 **Code → Download ZIP**([직접 다운로드](../../archive/refs/heads/main.zip))을 받고 압축을 풉니다. `실행.bat`이 있는 `racingcoach-main` 폴더를 엽니다.
3. **설치.bat**을 한 번 실행합니다. Python 패키지 설치와 `npm ci`·화면 빌드까지 자동으로 처리합니다.
4. [Google Drive 공유 폴더](https://drive.google.com/drive/folders/1MPvrKi4Zw9fInU5f84mCwe_Bt0uhW631?usp=sharing)에서 **전체 음성팩 1.3.0**을 받아 위 프로그램 폴더에 풉니다. ZIP의 `data` 폴더가 프로그램의 `data` 폴더와 합쳐져야 합니다.
5. **실행.bat**을 실행하면 **http://localhost:24157** 에서 앱이 열립니다. 실행 창을 유지하고 **설정 → 설치 설정**에서 IBT 폴더와 서비스 연결을 지정합니다.

별도 프로그램 ZIP은 배포하지 않습니다. 프로그램은 GitHub의 현재 소스, 음성만 Google Drive를 사용합니다. 기존 릴리즈 태그는 보존하며 최신 설치 절차는 위 **Code → Download ZIP**에 반영됩니다. 전체·버전별 업데이트 음성팩은 위 Google Drive 공유 폴더를 사용합니다. ZIP이 보이지 않으면 아직 업로드되지 않은 상태입니다.

### 기존 사용자 업데이트

1. 앱을 종료하고 기존 프로그램 폴더를 복사해 백업합니다.
2. **Code → Download ZIP**을 새로 받아 임시 위치에 풉니다. 그 안의 `실행.bat`, `src`, `scripts` 등 **내용물**을 기존 프로그램 폴더에 덮어씁니다. 새 `racingcoach-main` 폴더 자체를 기존 폴더 안에 넣지 마세요. 기존 `data`와 개인 설정은 삭제하지 않습니다.
3. **설치.bat**을 다시 실행해 필요한 패키지와 화면 빌드를 갱신합니다.
4. 현재 사용 중이던 버전의 **음성 업데이트팩 → 1.3.0**을 기존 프로그램 폴더에 풉니다. 이 팩들은 중간 버전을 거치지 않고 바로 적용합니다. 이미 받은 음성이 빠졌거나 버전을 모르면 전체 음성팩을 사용하세요.
5. **실행.bat**으로 다시 시작합니다. Git으로 복제한 사용자는 ZIP 덮어쓰기 대신 `git pull --ff-only` 후 설치.bat을 실행할 수 있습니다.

음성 ZIP 내부 경로는 `data/radio_audio/`, `data/spotter_audio/`입니다. 데이터 폴더나 음성 경로를 따로 지정했다면 그 실제 경로에 해당 폴더를 합쳐 주세요. 음성 변경이 0개인 업데이트팩은 받을 필요가 없습니다.

Google 키 없이도 로컬 주행 분석과 **받아 둔 고정 음성** 안내를 사용할 수 있습니다. 마이크 질문·AI 답변·새 문장 합성에는 본인의 Google Cloud 설정이 필요하며 사용 비용이 발생할 수 있습니다. Garage61 기준 수집에는 본인의 토큰을 사용합니다.

## 음성 설정

**음성 코치 → 음성·장치 세부 설정**에서 출력장치와 볼륨·속도를 조절합니다.

Bluetooth 등의 출력장치가 잠시 끊겨도 저장된 선택은 유지합니다. 장치를 사용할 수 없으면 앱 음성은 임시로 Windows 기본 출력으로 재생하고, 같은 장치가 돌아오면 다음 안내부터 원래 출력으로 복귀합니다. 직접 다른 장치나 Windows 기본 출력을 선택하면 그 선택을 유지합니다. Windows나 iRacing 자체의 오디오 설정은 변경하지 않습니다.

| 설정 | 기본값 | 범위 |
| --- | --- | --- |
| 스포터 속도 | 1.15배 | 1.0~1.4배 |
| 피트월 속도 | 1.15배 | 1.0~1.4배 |
| 여러 문장 속도 | 1.30배 | 1.0~1.4배 |
| 음성 볼륨 | 100% | 0~130% |

여러 문장 안내는 별도 속도만 적용하며 담당 속도와 곱하지 않습니다. 포메이션 브리핑은 1.15배 고정입니다. 음높이와 기존 저장값을 유지하고 속도 변경은 다음 안내부터 적용합니다. 볼륨의 100% 초과 구간은 빨간색이며, 소리가 찌그러지면 낮추세요. 게임 소리에 묻히면 Windows 볼륨 믹서에서 게임 소리를 낮출 수 있습니다.

## 배포와 데이터

- **GitHub:** 프로그램 소스와 버전별 Releases 설명. **Google Drive:** 전체 음성팩과 버전 간 음성 패치.
- 최초 설치는 전체 음성팩, 업데이트는 출발·대상 버전이 맞는 음성 패치를 받습니다. 음성팩 생성은 `python scripts/make_voice_pack.py --version 1.3.0 --from 1.0.0 1.0.1 1.0.2 1.1.0 1.2.0`으로 재현합니다. 다운로드 링크는 해당 릴리즈에 모읍니다.
- 키·토큰·개인 DB·주행 파일·녹음·음성 캐시·로컬 설정은 Git에 올리지 않습니다. 개인 데이터는 앱의 **설정**에 표시되는 데이터 폴더에 보관합니다.
- iRacing SDK는 **읽기 전용**입니다. 자동 보고·스포터는 AI를 호출하지 않으며, 측정값이 없으면 추측하지 않습니다. 개인 질문·AI 답변 음성과 녹음 원음은 디스크 음성 캐시에 저장하지 않습니다.
- 브라우저 설정을 유지하려면 화면 주소 **http://localhost:24157** 을 사용하세요.

## 개발

새로 복제한 저장소에서는 `git config core.hooksPath .githooks`를 실행하세요. 커밋 전에는 스테이징 파일, push 전에는 전체 이력의 비밀 정보·개인 데이터 포함 여부를 검사합니다.

```powershell
python scripts/audit_git.py --staged
python scripts/audit_git.py --history
python -m unittest discover -s iRacing_Backend -p 'test_*.py'
python -m unittest discover -s scripts -p 'test_*.py'
$env:CI='true'
npm test -- --watchAll=false --runInBand
npm run build
```

화면 소스를 변경하면 빌드를 다시 실행하세요. 개발 서버는 `python scripts/launch_app.py --dev`로 실행합니다. 기존 버전 태그는 유지하며 새 배포는 새 버전의 태그와 릴리즈로 추가합니다.
