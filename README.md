<p><strong>다음 업데이트 · Garage61 비교:</strong> 대표 실주행 한 랩의 속도·페달·조향·라인·시간차를 함께 비교합니다. 비교 변경에서 대표 드라이버를 고를 수 있으며, 다른 선택 기록은 조건에 맞는 드라이버별 보조 근거로 사용합니다. 새 기록을 받아도 선택한 기준을 유지합니다. 자세한 사용법은 <a href="manual/매뉴얼.html">매뉴얼</a>을 참고하세요.</p>
<p><strong>다음 업데이트 · 기준 불러오기:</strong> Garage61은 같은 차량·코스의 파일만 상세 검사합니다. 비교 창 상단에 파일 읽기·기준 확인·랩 비교 로딩바를 표시하며, 새 자료 수집 중에는 별도 진행 상태를 확인할 수 있습니다.</p>
<p>비교창에서 주행 파일을 고르면 파일을 읽은 직후 Garage61 자료를 확인하고, 부족하거나 오래된 자료는 자동 수집 설정에 따라 다운로드를 시작합니다. 비교 버튼을 누를 필요는 없습니다. 최신 자료 재사용·다른 다운로드 대기·재수집 대기·오류 이유를 표시하며, 완료되면 열린 창의 기준 목록을 갱신합니다. 선택해 둔 내 기준이나 Garage61 대표 랩은 새 자료로 자동 교체하지 않습니다.</p>
<p>비교창은 내 주행과 기준 선택을 두 열로 배치합니다. 재수집 제한이면 상단에 <strong>SKIPPED_COOLDOWN · 재수집 생략</strong>과 이유를 표시합니다. 다운로드 대기가 아니므로 받은 자료나 내 기준 랩으로 비교할 수 있습니다. 자세한 조건 설명은 '비교 기준 안내'에서 펼칩니다.</p>

<h2>01 &nbsp; 어느 코너에서 시간을 잃었는지</h2>

<p>분석 화면 상단에는 IBT·DuckDB 파일의 총 주행시간을 표시하고, 세로 구분선으로 선택한 내 랩타임과 구분합니다.</p>

<p>경기 순위 변화에서 참가 차량을 선택하면 확인된 인시던트·피트 진입/복귀·무효 랩·베스트 기록을 그래프 안에 표시합니다. 주행 사건과 랩 기록을 각각 켜고 끌 수 있으며, 다른 차량에서 확인되지 않는 정보는 추정하지 않습니다.</p>

<p>내 랩과 기준 랩을 같은 거리에서 비교합니다. 지도와 브레이크·스로틀·속도 그래프를 함께 보며, 제동 시작부터 탈출까지 차이가 생긴 지점을 확인하세요.</p>

<h2>03 &nbsp; 주행 중에는 한국어 안내로</h2>

<p><strong>세션별 오버레이:</strong> 왼쪽 <strong>오버레이</strong>에서 연습·퀄리·레이스·포메이션별로 코칭 카드 또는 입력값 그래프를 골라 저장합니다. <strong>자동 주행 코칭</strong>은 과제·비교 기록·코너 분석 없이 정상 주행 약 1초 뒤부터 최근 10초의 무입력·동시 입력 시간을 관측하고, 제동 해제 후 가속이 확인되면 연결 시간도 관측합니다. 결과는 여유 있는 직선에서 표시합니다. 기본 추천은 자동 관측이며 연습 목표·성공률은 선택 기능입니다. 카드 항목은 여러 개 체크하며, 상황에 맞는 측정값을 최대 3개 표시합니다. <strong>내용 표시 방법</strong>에서 항목별 조건과 실제 자료 준비 상태를 확인하세요. 코너별 비교는 같은 차량·트랙 파일을 분석해 구간을 준비하면 사용할 수 있습니다. iRacing은 Garage61 기준이 없을 때 비슷한 조건의 개인 기록을 찾고, LMU는 개인 기록만 사용합니다. 반복 패턴은 깨끗한 통과 3회, 공통 패턴은 비슷한 조건 5회, 접촉 전후는 신호 전 2랩과 후 1랩이 필요합니다. 관측값을 실수·손실 원인으로 확정하지 않습니다. 창 크기·위치·불투명도·자동 표시는 <strong>창·표시 설정 → 설정 열기</strong>에서 조절하며, 화면 미리보기는 샘플입니다.</p>
<p><strong>읽기 쉬운 직선 코칭:</strong> 연속 코너에서는 결과를 모으고, 다음 직선에서 관측된 양의 시간 차이가 가장 큰 코너를 우선 선택합니다. 선택한 결과와 수치는 6초간 고정하고 새 내용은 최소 8초 간격으로 표시합니다. 알려진 다음 제동·회전까지 8초 이상 여유가 있을 때 시작하고, 진입 2초 전이나 실제 제동·조향·근접 상황에서는 상세 내용을 접습니다. 예측 자료가 없는 첫 주행은 실제 입력이 2초간 안정된 뒤 표시하며, 다음 코너를 미리 안다고 가정하지 않습니다. 큰 제목·수치·빠름/느림 설명과 기준 랩타임을 창 전체에 배치합니다. 급유 등 기존 하단 알림이 나오면 보조 정보 자리를 비웁니다. 전체 적용은 앱과 검은 실행창을 완전히 종료 후 재실행하세요.</p>

<p><strong>실제 배치로 미리보기:</strong> 앱 중앙·크게 보기·네 세션 비교 모두 Windows 오버레이와 같은 코드로 그래프·페달 막대·기어·코칭 카드를 그립니다. 창 크기·글자 크기·표시/배경 불투명도를 반영하고 좁은 공간에서는 비율을 유지해 축소합니다. 수치는 샘플이며 게임 입력이나 개인 기록을 읽지 않습니다.</p>
<p>좌우 차량과 주요 경기 상황은 스포터가, 연료·순위·피트 정보는 피트월이 알려 줍니다. F8을 누른 채 질문하거나 주행 중 느낀 점을 메모로 남길 수 있습니다.</p>
<p>음성 코치의 스포터·피트월 맨 아래에서 상황별 안내를 개별로 켜고 끕니다. 문구 예시·전체 선택·기본값 복구를 제공하며 두 게임의 선택을 따로 저장합니다.</p>
<p><strong>2.3.1 랩타임·음성 복구:</strong> 랩타임은 랩 완료 감지 후 2초 안에 재생을 시작할 수 있을 때만 안내합니다. 좌우 차량·가까운 앞뒤 차량, 질문·다른 음성 때문에 늦어지면 생략합니다. 퀄리 순위는 랩타임과 별도로 안내합니다. 음성 준비 응답이나 재생이 멈추면 해당 안내를 건너뛰고 다음 안내를 다시 시도합니다. 자세한 조건은 <a href="manual/radio-timing-recovery.md">랩타임·음성 정지 복구 안내</a>를 참고하세요. 적용하려면 앱과 검은 실행창을 완전히 종료한 뒤 다시 실행하세요.</p>
<p>2.2.1: 다른 탭이 음성을 담당하면 피트월에 대기 이유를 표시하고 취소 기록의 중복을 방지합니다. LMU 본인 완주 신호를 결과 음성에 연결하고, 새 안내 로그에는 수집 당시 화면·백엔드 버전과 내보내기 버전을 구분해 남깁니다. 새 음성은 없으며 음성팩 2.2.0을 그대로 사용합니다.</p>
<p>2.2.0 보완: 순위 상승·하락은 마지막으로 재생을 끝낸 순위와 비교하며, 전달 여부가 불확실하면 현재 순위만 안내합니다. 같은 경기에서 잠깐 연결이 끊겨도 시작 브리핑을 반복하지 않습니다. 완주·로그 내보내기·순위 그래프 조회 때 저장 대기 중인 타이밍 기록을 반영하고, 취소된 직선 보고는 다음 기회에 다시 선택할 수 있게 했습니다.</p>

<h2>설치와 첫 실행</h2>

<p>Windows x64에서 사용합니다. 처음 설치용 ZIP에는 Python과 화면 빌드가 포함돼 있어 Python·Node.js·PATH를 따로 설정할 필요가 없습니다.</p>

<ol>
<li><a href="https://github.com/elsalvadoruk-hue/racingcoach/releases/latest"><strong>최신 Releases</strong></a>에서 <code>racingcoach-setup-*.zip</code>을 받아 압축을 풉니다.</li>
<li><code>설치.bat</code>을 한 번 실행한 뒤 <code>실행.bat</code>으로 앱을 켭니다. 최초 설치에는 인터넷이 필요합니다.</li>
<li>업데이트 창의 <strong>빠진 음성 받기</strong>로 고정 안내 음성을 받습니다. 첫 다운로드는 약 0.66GB입니다.</li>
<li><strong>설정 → 설치 설정</strong>에서 게임의 주행 기록 폴더를 지정합니다. Google Cloud·Garage61은 사용할 기능에 맞춰 연결합니다.</li>
</ol>

<p>화면 주소는 <strong>http://localhost:24157</strong>을 사용하세요. 평소에는 <code>실행.bat</code>만 실행하고, 함께 열린 실행 창은 유지합니다.</p>

<p>최신 사용법은 앱 왼쪽 아래 <strong>사용 가이드</strong>에서 확인하세요. <a href="https://github.com/elsalvadoruk-hue/racingcoach/raw/refs/heads/main/manual/매뉴얼.html">오프라인 HTML 매뉴얼</a>은 이전 1.3.0 화면 기준의 참고 자료입니다.</p>

<p>2.2.0: <a href="manual/피트월-설정추천과-경기결과.md">설정 추천 표시·완주 결과와 지원 범위</a>.</p>
<p>공식 문서에서 확인한 iRacing 차량의 ARB 시험 추천을 연결했습니다. 음성팩 2.2.0에 숫자 없는 설정 안내 14문장을 추가했습니다. 설정 → 업데이트 → 빠진 음성 받기로 받을 수 있습니다. 윙·공기압은 실제 장착값을 확인할 수 있는 연결이 필요하며 LMU의 새 설정 추천과 구분합니다.</p>
<p>레이스·인듀런스 주행 파일의 <strong>순위 변화</strong>에서 내 클래스 차량의 순위 이력을 봅니다. 각 차량이 스타트·피니시 라인을 통과해 완료한 랩의 순위를 점으로 찍고 얇은 사선으로 잇습니다. 왼쪽 버튼으로 오른쪽 드래그하면 확대, 왼쪽 드래그하면 이전 범위로 돌아갑니다. 휠은 세로 스크롤, 아래 막대는 좌우 이동입니다. 원본 순위·완료 랩 채널 또는 같은 경기임을 확인한 로컬 기록이 있는 구간만 표시합니다.</p>
<p>선이나 참가 차량을 클릭하면 강조를 고정합니다. 다른 선에 마우스를 올리면 고정한 차량과 함께 비교할 수 있고, 다른 차량 클릭으로 대상을 바꾸거나 <strong>전체 보기</strong>로 해제합니다.</p>
<p><strong>분석·차량 상세</strong>는 분석 화면 위쪽의 순위 변화·코너 번호 확인 옆에 있습니다. 로그 보내기를 켜면 상단 버튼은 아이콘만 표시합니다. 앱 버전과 GitHub 링크는 하단 중앙에, 코너 이동·그래프 집중·전체화면(F11) 안내는 하단 오른쪽에 있습니다.</p>
<p>iRacing IBT에 내 순위만 있어도 앱이 레이스 중 약 1초마다 자동 저장한 로컬 순위 기록에서 같은 클래스의 다른 차량을 추가합니다. 자동 보내기나 진단 기록을 켤 필요가 없으며, 앱을 켜지 않아 기록되지 않은 다른 차량의 과거 순위는 복원하지 않습니다.</p>

<h2>업데이트</h2>

<p>앱 시작 시 새 버전이 있으면 업데이트 창에서 <strong>업데이트 받기 → 지금 다시 시작해서 적용</strong>을 선택합니다. 기존 기록·설정·키·토큰·음성은 보존됩니다.</p>

<p>켜 둔 동안 나온 업데이트와 추가 음성은 <strong>설정 → 업데이트</strong>에서 확인할 수 있습니다. 업데이트 창은 주행 중에 자동으로 뜨지 않습니다.</p>

<details>
<summary>이전 버전에서 옮기기 · 음성을 직접 받기 · 소스로 실행하기</summary>
<p>구버전의 수동 이전과 음성 다운로드 문제는 <a href="manual/설치-상세-안내.md">설치 상세 안내</a>와 앱의 <strong>사용 가이드</strong>를 참고하세요. 개인 데이터 폴더는 삭제하지 마세요.</p>
<p>개발용 소스에는 내장 Python과 화면 빌드가 포함되지 않습니다. Python 3.12와 Node.js LTS 환경에서 <code>설치.bat</code>을 실행합니다. 검증 명령과 구조는 <a href="manual/개발-안내.md">개발 안내</a>를 확인하세요.</p>
</details>

<h2>서비스 비용과 데이터</h2>

<ul>
<li><strong>기본 분석과 고정 안내:</strong> 로컬 주행 분석과 받아 둔 고정 음성은 Google 키 없이 사용할 수 있습니다. 자동 보고·스포터는 AI를 호출하지 않습니다.</li>
<li><strong>선택 서비스:</strong> 마이크 음성 인식·AI 답변·새 문장 합성은 본인의 Google Cloud를 사용하며 비용이 발생할 수 있습니다. Garage61 수집에는 본인 토큰이 필요합니다.</li>
<li><strong>주행과 개인정보:</strong> SDK는 읽기 전용입니다. 측정값이 없으면 추측하지 않습니다. 녹음 원음과 개인 질문·AI 답변 음성은 디스크에 저장하지 않습니다.</li>
<li><strong>로그 보내기:</strong> 자동 전송은 사용자가 동의해 켰을 때 동작합니다. 전송 항목을 확인하고 앱에서 사용 여부를 선택할 수 있습니다.</li>
<li><strong>개발 중인 로그 진단 보완(미공개):</strong> 음성이 없는 주행도 연결 상태를 확인할 수 있도록 보관량을 제한한 로컬 기록을 추가했습니다. <a href="manual/radio-timing-recovery.md">기록 범위와 한계</a>를 참고하세요. 자동 보내기 설정은 변경하지 않습니다.</li>
</ul>
