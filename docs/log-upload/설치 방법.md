# 세션 로그 받는 스크립트 설치

앱의 "보내기"와 "세션 로그 자동 보내기"는 이 스크립트의 웹 앱 주소로 로그를 보냅니다. 스크립트가 받은 로그를 내 Drive 폴더 `iracingcoach`에 저장합니다.

- 폴더 공유는 **제한됨** 그대로 둡니다. 스크립트는 폴더 주인(나)의 권한으로 저장하므로 공유하지 않아도 됩니다. 링크 공개로 바꾸면 다른 사람도 로그를 볼 수 있게 되니 바꾸지 마세요.
- 앱에 들어가는 것은 웹 앱 주소뿐이고, 이 주소로는 로그를 올리는 것만 됩니다(읽기·삭제 불가).

## 1. 스크립트 만들기

1. https://script.google.com 에 폴더 주인 계정으로 로그인하고 **새 프로젝트**를 만듭니다. 이름은 `iracingcoach-log`처럼 정합니다.
2. 기본 `Code.gs` 내용을 모두 지우고 이 폴더의 `Code.gs` 내용을 붙여 넣은 뒤 저장합니다. 맨 위 `FOLDER_ID`가 `1abVdFut9s7QYgXljyOgAiEUwmO1c3gR8`인지 확인합니다.

## 2. 웹 앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 유형 선택(톱니바퀴)에서 **웹 앱**을 고릅니다.
3. **다음 사용자 인증 정보로 실행: 나**, **액세스 권한이 있는 사용자: 모든 사용자**로 둡니다. (앱이 로그인 없이 보낼 수 있게 하는 설정이며, 폴더는 계속 비공개입니다.)
4. **배포**를 누르고 권한 확인 창에서 내 계정으로 허용합니다. "확인되지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 누릅니다. 내가 만든 스크립트라 괜찮습니다.
5. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

## 3. 앱에 주소 넣기

프로젝트 루트에 `log-upload-url.txt`를 만들고 첫 줄에 웹 앱 URL을 넣습니다. 앱을 다시 켜면 "보내기"와 상단 "로그 보내기" 버튼이 나타납니다.

## 4. 1년 지난 로그 지우기 (동의 창에 적은 보관 기간)

스크립트 편집기 왼쪽 **트리거(시계 아이콘) → 트리거 추가**에서 함수 `deleteOldLogs`, 이벤트 소스 **시간 기반**, **일 단위 타이머**로 만듭니다. 받은 지 1년이 지난 로그를 휴지통으로 옮깁니다.

## 이미 배포해 둔 스크립트가 있을 때

예전에 만든 스크립트가 있으면 새로 만들 필요 없습니다. 그 프로젝트를 열고 이 `Code.gs`로 바꾼 뒤 아래 "스크립트를 고친 뒤" 순서로 같은 주소에 다시 배포합니다. 주소는 **배포 → 배포 관리**에서 복사할 수 있습니다.

## 스크립트를 고친 뒤

**배포 → 배포 관리 → 편집(연필) → 버전: 새 버전 → 배포**로 같은 주소를 유지한 채 바꿉니다. "새 배포"를 다시 만들면 주소가 바뀌어 앱의 주소도 바꿔야 합니다.
