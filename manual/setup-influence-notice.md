# 셋업 영향 가능성 안내 — 판정 규칙 v1

Garage61과 비교할 때 코너 이득을 직선 손실이 상쇄하는 관측을 랩타임 아래에 표시한다. 셋업 원인 확정·확률·변경 후보·A/B 효과 학습과 분리한 안내다. 현재 iRacing의 외부 기준 비교에 적용하며 LOCAL과 LMU에는 표시하지 않는다.

표시 문구:

> **셋업 영향 가능성 있음** · 랩 전체
>
> 코너에서 시간을 벌지만 직선에서 손실이 반복됩니다. 셋업 차이가 영향을 줬을 수 있습니다.

## 표시 조건

모두 충족해야 한다. v1의 문턱은 보수적인 관측 필터이며 실차량 전반에서 보정된 통계적 신뢰도는 아니다.

1. 유효한 완주 랩이며 전체 시간 차이가 +0.05초 이상이다. 전체 거리 축·시간·속도·스로틀·브레이크·조향에 결측이 없어야 한다. 시간은 증가해야 하며 헤더의 랩 차이와 그리드의 차이가 0.1초 이내로 일치해야 한다.
2. 겹치지 않는 코너가 3개 이상이다. 그중 3개 이상·60% 이상에서 각 0.02초 이상 이득이고, 코너 합계도 0.05초 이상 이득이다.
3. 코너 밖의 손실이 코너 순이득보다 0.05초 이상 크다. 코너 밖 시간은 랩 시간에서 겹침 없는 코너 시간을 뺀 값으로 구한다. 이 값 전체를 셋업 때문에 잃은 시간이라고 해석하지 않는다.
4. 기존 직선 감지 결과를 코너 밖 구간으로 잘라 다시 측정한다. 풀스로틀이 코너 종료 전에 시작해도 코너 부분은 근거에 넣지 않는다. 잘라낸 뒤에도 220m 이상인 서로 다른 직선 두 곳 이상에서 아래 조건이 반복된다.
   - 직선 초반 기준 대비 속도 부족이 2.5km/h 이하, 후반 부족이 2.5km/h 이상이며 부족 폭이 1.8km/h 이상 커진다.
   - 두 랩 모두 관측 표본의 98% 이상에서 스로틀 94% 이상, 브레이크 3% 이하, 핸들 각도 절댓값 5도 이하다.
   - 해당 구간의 실제 시간 손실이 각각 0.03초 이상이다.
5. 위 구간에서 직접 확인한 풀스로틀 손실의 합계가 0.1초 이상이고 코너 밖 순손실의 절반 이상이다. 한 직선의 여러 조각은 가장 큰 손실 한 조각만 집계한다. 출발선 앞뒤로 갈라진 직선도 한 곳으로 센다.
6. 선택된 분석 기준에 알려진 노면·타이어·BOP 부적합이 없고 기존 조건 점수가 0.45 미만이 아니다. 알려진 연료 차이 15L 초과·노면 온도 차이 10°C 초과·풍속 차이 15km/h 초과는 표시를 보류한다. 기존 호환성·분석·추천 문턱은 변경하지 않는다.

## 예상 상황별 처리

| 상황 | 처리 |
| --- | --- |
| 코너에서 대체로 빠르지만 비슷한 초반 속도에서 여러 직선 후반에 뒤처짐 | 조건 충족 시 가능성 안내 |
| 코너 탈출부터 느리며 직선에서 속도 부족이 더 커지지 않음 | 표시 안 함, 기존 탈출 분석 유지 |
| 코너와 직선 모두 느림 / 랩 전체가 이미 빠름 | 이번 안내 대상 아님 |
| 한 직선만 차이 / 한 직선의 중복 조각 / 출발선 앞뒤 두 조각 | 반복 근거 부족으로 표시 안 함 |
| 코너 밖 손실 대부분이 풀스로틀 이전에 발생 | 표시 안 함 |
| 리프트·잔여 제동·큰 조향·결측·불완전 랩 | 표시 안 함 |
| 알려진 큰 비교 조건 차이 | 표시 보류 |
| 상대 한 랩만 선택 | 서로 다른 직선 반복으로 안내 가능, 셋업 원인 확정은 계속 불가 |
| 파일·랩·기준 변경 | 새 비교 결과로 교체, 이전 안내를 이어받지 않음 |

## 해석 한계

Garage61 상대 셋업을 역산하지 않는다. 단일/종합 기준 모두 같은 관측 필터를 쓰며, 종합 곡선은 한 사람의 실제 주행이 아니다. 모르는 슬립스트림·연료·풍향·차량 손상·변속·출력 상태 등의 영향을 배제했다고 말하지 않는다. 알려진 조건을 통과해도 원인은 미확정이다. 데이터가 부족해 안내가 없다는 사실은 셋업 영향이 없다는 뜻이 아니다.

제품 계산은 `iRacing_Backend/setup_influence.py`, UI는 `src/desktop/SetupInfluenceNotice.jsx`에 있다. 기존 직선 진단과 랩 그리드를 재사용하며 외부 요청이나 원본 재파싱을 추가하지 않는다.
