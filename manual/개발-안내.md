# 개발 안내

FastAPI 백엔드는 `iRacing_Backend/`(24158), React 화면은 `src/`(24157), 런처·패키징은 `scripts/`에 있습니다. Windows SDK와 F8 전역 키를 사용합니다. 화면 주소는 **http://localhost:24157**을 유지합니다.

## 소스로 설치·실행

Python 3.12와 Node.js LTS가 필요합니다. 저장소를 복제한 뒤 `설치.bat`을 실행하고 `실행.bat`으로 켭니다. 소스 ZIP에는 Python 런타임과 화면 빌드가 없습니다. 개발 서버는 `python scripts/launch_app.py --dev`로 실행합니다.

새 저장소에서는 `git config core.hooksPath .githooks`를 실행하세요. 커밋 전 스테이징 파일, push 전 전체 이력의 비밀 정보·개인 데이터 포함 여부를 검사합니다. 키·토큰·개인 DB·주행 기록·로그·음성 캐시·로컬 설정은 Git에 넣지 않습니다.

## 검증

테스트는 임시 데이터 폴더를 사용하고 Google API는 mock으로 대체합니다. 실제 앱의 DB와 과금 서비스를 사용하지 마세요. 아래 명령은 프로젝트 루트에서 실행합니다.

```powershell
python scripts/audit_git.py --staged
python scripts/audit_git.py --history
python -m unittest discover -s iRacing_Backend -p 'test_*.py'
python -m unittest discover -s scripts -p 'test_*.py'
$env:CI='true'
npm test -- --watchAll=false --runInBand
npm run build
```

화면 소스나 `public/`을 바꾸면 빌드를 다시 실행합니다. 런처는 최신 `build/`가 있으면 같은 주소에서 서빙하며, 오래된 빌드일 때 개발 서버로 전환합니다.

수치·판정은 프로그램이 계산하고 관측이 부족하면 확인 필요로 둡니다. SDK는 읽기 전용이며 지난 상황의 안내는 재생 전에 폐기합니다. 고정 음성만 디스크에 캐시하고 개인 질문·AI 답변 음성·녹음 원음은 저장하지 않습니다. 셋업 효과는 조건이 맞는 단일 변경 A/B로만 판단합니다.

## 패키지와 LMU

배포본의 Python은 `scripts/python_runtime.json`에 고정한 런타임을 사용합니다. 앱 업데이트 ZIP은 `runtime/`을 제외하며 설치 ZIP만 런타임을 포함합니다. 시스템 Python·PATH를 변경하지 않습니다.

LMU 기본 경로는 설치된 SDK 헤더를 읽는 Python 리더와 잠금 전용 DLL입니다. SDK를 게임 설정 변경에 사용하지 않습니다. 기존 native bridge는 명시적 rollback 경로로 보존합니다. 자세한 구조는 [LMU 개발 안내](lmu-development.md), 배포 명령은 [자동 업데이트 배포 방법](자동-업데이트-배포.md)을 확인하세요.

버전별 변경은 [Releases](https://github.com/elsalvadoruk-hue/racingcoach/releases)와 [패치 노트](../패치%20노트.txt)에 기록합니다. 소스 공개는 자유 재배포 허가를 뜻하지 않으며 [이용조건](../LICENSE.md)을 따릅니다.
