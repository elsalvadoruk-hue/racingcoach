# 포장 오벌 공개 범위와 로그 전송 안내

2026-10-29 **앱 2.4.3** 기준입니다. 2.4.2를 바탕으로 포장 오벌 시험 기능과 로그 재동의 안내를 제공합니다. 기본 음성팩 2.4.3도 함께 제공합니다.

오벌 개발 대상은 **포장 오벌**입니다. 더트 오벌은 사용자 결정에 따라 후속 개발 계획에서도 제외합니다. 로그의 `DIRT_OVAL` 구분은 포장 오벌 전용 동작을 잘못 적용하지 않기 위해 유지하며, 더트 전용 안내·음성·절차는 개발하지 않습니다.

## 업데이트 후 로그 전송 재동의

기존에 자동 보내기를 켠 사용자의 저장된 동의문 버전과 새 동의문 버전이 다르면 자동 전송을 멈추고, 첫 화면에서 **로그 전송 동의 내용이 변경되었습니다**를 표시합니다. 주요 변경 사항과 전체 내용을 보여 주며 체크 후 **다시 동의하고 켜기**를 눌러야 재개합니다. 재동의한 뒤 시작하는 주행부터 보냅니다.

**나중에** 또는 Escape로 닫아도 자동 보내기는 중지된 상태이며, 같은 탭 세션에서는 자동 창을 반복해서 띄우지 않습니다. 상단 **로그 재동의**와 세션 로그의 **변경 내용 확인**에서 다시 열 수 있습니다. **자동 보내기 끄기**는 기존 동의를 해제하므로 재동의 요청도 사라집니다. 새 사용자·직접 꺼 둔 사용자·현재 동의문에 이미 동의한 사용자에게는 이 재동의 창을 자동으로 띄우지 않습니다. 동의 내용이 그대로인 앱 패치는 기존 동의를 유지합니다.

앱 버전과 `CONSENT_VERSION`은 별개입니다. 전송 범위나 동의 내용이 바뀌면 동의 버전과 주요 변경 목록도 함께 갱신합니다. 이번 4번 동의문은 오벌 변경 전체를 포함합니다. 실제 사용자 설정을 작업 중 대신 바꾸지는 않습니다.

## 음원 받기와 검증

`python scripts/prepare_oval_voice_list.py --out oval-voice-checklist.json`으로 14문장 제작·청취 체크리스트를 만듭니다. 이 명령의 출력은 문구 목록이며 음원이나 설치팩이 아닙니다. 실제 기본 음성은 **설정 → 업데이트 → 빠진 음성 받기**로 받습니다. 개인 키·음성 폴더를 읽거나 합성하지 않습니다.

앱의 기존 역할팩 **추가 문장** 목록에도 14문장을 연결했습니다. 기준 목록이 없는 과거 팩은 기존처럼 차이를 확정하지 못합니다. 기존 좌우 음성 누락을 강제로 이 14문장으로 대체하지 않습니다. 기본 음성팩 2.4.3에 네 목소리 총56개를 제작·디코딩 검증해 포함했습니다. 커스텀팩의 추가 문장은 해당 팩에서 별도 준비합니다. 새 음원의 사람 한국어 청취·새 실주행 검증은 남아 있습니다.

## 로그를 받은 뒤 확인할 것

1. `scripts/review_coach_logs.py`로 중복을 제외하고 `coverage.json`의 관측·미관측을 확인합니다. 기록 수를 사람 수·경기 수로 쓰지 않습니다.
2. 기본 근접 안내는 실제 재생 이력과 관측 겹침·유지·클리어를 대조합니다. 10Hz 표본 사이의 실제 위치가 필요하면 선택적인 상황 설명·영상을 확인합니다.
3. 코션·한 랩 전 철회·정상 그린·연속 코션·도중 접속·피트 허용 변경·대열·후미·프리 패스·웨이브 어라운드를 따로 검수합니다. 경기 옵션과 게임 지시의 의미가 확인된 기능만 후속 발화를 검토합니다.
4. 위트는 안전·부하·발화 여유·다른 음성 점유·반복 이력과 근거를 확인합니다. 세션 베스트를 생애 최고로, 순위표 상승을 추월로, 체커를 본인 완주로 확정하지 않습니다. 해당 후보에는 별도 보류 이유가 남습니다.
5. `regression.json`의 사건 전후 표본을 회귀 자료로 사용합니다. 생략·결측·시계 반복 구간을 이어 붙이지 않으며 실제 30Hz 판단 재현으로 취급하지 않습니다.

실제 오벌 로그·한국어 청취·다른 PC 검수는 대기입니다. 자동 검사와 버전·패키지·격리 업데이트 검증은 실제 주행·사람 청취 검증과 구분합니다. 로그가 쌓여도 절차·위트 발화는 자동으로 켜지지 않습니다.
