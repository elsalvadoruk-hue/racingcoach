# 설정 추천 표시와 완주 결과

2026-10-24 로컬 구현. 공개 2.1.2에는 아직 포함되지 않았습니다.

스포터·피트월 음성 설정과 주행 오버레이 자동 표시를 켜서 사용합니다. 앱은 게임의 설정을 대신 조작하지 않습니다. 음성은 설정 이름과 방향을 짧게 말하며 목표 숫자를 읽지 않습니다.

## ABS·TC·브레이크 바이어스

같은 설정으로 수집한 최근 깨끗한 세 랩을 비교합니다. 제동 또는 가속 중 반대 조향이 지속된 지점이 두 랩 이상에서 반복돼야 자동 추천 후보가 됩니다. 여러 곳의 서로 다른 실수만으로 설정 문제를 단정하지 않습니다. 피트·사고·옆 차량·기록 단절이 있는 랩은 제외하며 설정을 바꾸면 이전 설정의 근거를 버립니다.

- 제동 중 뒤가 반복해서 흔들리면 브레이크 바이어스를 앞쪽으로 옮겨 시험하도록 제안합니다.
- 가속 중 같은 구간에서 반복해서 자세를 바로잡으면 TC 개입을 늘려 시험하도록 제안합니다.
- 제동 중 불안정과 낮은 ABS 개입이 함께 반복되면 ABS 개입을 늘려 시험하도록 제안합니다. 휠 잠김이나 원인을 확정한 진단은 아닙니다. ABS 개입이 지나치게 잦으면 설정 변경보다 제동 압력을 먼저 점검합니다.

TC를 낮추거나 바이어스를 뒤로 옮기는 제안은 조용한 랩이라는 이유만으로 만들지 않습니다. 타이어·조작·노면 원인을 모두 배제한 최적 셋업 계산도 아닙니다.

한 번에 하나를 선택합니다. 대기·실패·만료된 음성은 전달 성공으로 세지 않으며 실제 재생을 시작한 항목은 10분 동안 반복 제안을 쉬게 합니다. 위험 안내는 기존 우선순위를 따릅니다.

## 오버레이 표시

실제 추천 음성이 재생을 시작하면 그래프 아래 안내 줄에 항목 이름, 현재값, 목표값 또는 방향이 나타납니다. 첫 4초는 글자를 지우지 않고 테두리와 목표 색만 천천히 바뀝니다. 최초 표시부터 최대 30초이며 같은 이벤트의 재수신으로 연장되지 않습니다.

새 ARB 음성이 아직 없으면 같은 추천을 오버레이로만 표시합니다. 음성 파일이 없거나 읽는 도중 사라져도 자동 합성하지 않습니다. 이 경우 화면 표시 시점부터 30초·10분 반복 제한을 계산합니다.

주행 중 목표값에 도달한 새 표본 두 개를 확인하면 바로 닫습니다. 일부만 변경했으면 현재값을 갱신하고, 반대 방향으로 바꿨으면 추천을 취소합니다. 숫자 목표를 모르는 TC·ABS는 설정 변경 시 이전 안내를 취소하며 목표 도달로 간주하지 않습니다. 데이터가 끊기거나 리플레이·다른 세션으로 넘어가면 이전 표시를 유지하지 않습니다.

현재 SDK 연결은 차량별 조절 간격·상하한을 모두 제공하지 않습니다. 브레이크 바이어스는 같은 주행에서 실제로 관측된 반복 조절 간격과 이미 도달한 값의 범위 안에서만 숫자 목표를 만듭니다. 범위 밖이거나 처음 읽는 차량은 방향만 표시합니다. TC·ABS 번호의 개입 강도 순서는 추측하지 않으며, 특히 LMU ABS 맵은 번호순 강도가 아닙니다.

## 피트에서 바꿀 수 있는 항목

공식 차량 매뉴얼 65개와 릴리스 노트에서 확인한 조절 지원을 차량별로 연결했습니다. iRacing의 실제 차량 경로가 일치하고, 고정 셋업이 아니라는 정보가 있어야 새 ARB 추천을 만듭니다. 목록 밖의 차량은 미확인이며, 게임에서 조절 불가라고 단정하지 않습니다.

| iRacing 차량 | ARB 추천 범위 | 윙 피트 조절 확인 |
| --- | --- | --- |
| 현행 GT3 11종 | 앞·뒤, 다음 피트 | 있음 |
| GTE 5종 | 앞·뒤, 다음 피트 | 이번 연결 대상 아님 |
| Acura ARX-06·BMW M Hybrid V8·Cadillac V-Series.R·Porsche 963 | 앞·뒤, 주행 중. 직선에서만 안내 | 이번 연결 대상 아님 |
| Dallara IR18 | 앞·뒤, 주행 중 | 이번 연결 대상 아님 |

GT3는 Acura NSX EVO 22, Aston Martin Vantage EVO, Audi R8 LMS EVO II, BMW M4, Corvette Z06, Ferrari 296, Ford Mustang, Lamborghini Huracán EVO, McLaren 720S EVO, Mercedes-AMG EVO, Porsche 992 GT3 R입니다. GTE는 BMW M8, Corvette C8.R, Ferrari 488, Ford GT 2017, Porsche 911 RSR입니다. 계열 이름만으로 레거시 차량이나 새 차를 포함하지 않습니다.

**ARB 방향 추천**은 제동·강한 가속을 피한 코너 중간의 신호를 사용합니다. 최근 깨끗한 세 랩 중 두 랩에서 서로 떨어진 두 위치의 반대 조향이 반복되고 속도·스로틀·연료·노면 조건이 맞으면 뒤 ARB를 부드럽게 시험하도록 제안합니다. 앞 ARB는 다섯 랩 이상에서 앞선 두 랩 이상의 회전 반응과 비교하고, 최근 두 랩의 같은 두 위치에서 비슷한 속도·스로틀에도 조향이 늘고 회전 반응이 줄어야 제안합니다. 원인을 확정하거나 최적값을 보장하는 판정은 아닙니다. 한 번에 하나를 시험하며 다른 설정이 바뀌면 이전 근거를 버립니다.

SDK의 `dcAntiRollFront/Rear`는 차량별 내부 단계일 수 있어 화면 숫자로 표시하지 않습니다. IR18·SFL의 설명서 순서와 Cup 992.2의 불규칙한 강도 순서는 별도 저장했지만 실제 화면값을 확인하지 못하면 방향만 표시합니다. Mission R 설명서의 중간 단계 방향은 문장끼리 충돌해 숫자 순서를 추측하지 않습니다.

**윙·공기압**은 지원 정보와 비교 계산을 연결했습니다. 숫자 목표를 만들려면 실제 장착값을 확인하고, 본인이 같은 조건에서 한 항목만 바꾸어 각각 세 랩 이상 달린 결과가 필요합니다. 전체 랩의 반복 이득이 기록 편차보다 커야 이전에 사용한 값만 후보로 삼습니다. 직선 최고속만으로 윙을 낮추거나 모든 차에 같은 열간 공기압을 적용하지 않습니다.

현재 iRacing 연결의 `CarSetup`은 Garage 스냅샷이고 `dpWingRear`·`PitSv*P`는 예약 정보입니다. 피트 이후 실제 장착 윙·냉간 공기압을 확인하는 신호가 없어 **현재 앱에서는 윙·공기압 자동 목표 추천이 나오지 않습니다.** 비교 계산에 합성 검증값을 넣어 시험한 결과와 실제 사용 지원을 구분합니다. F6의 피트 갱신 온도·마모도 실시간 열간값으로 사용하지 않습니다. 공기압 예약값이 목표와 같은 새 표본 두 개를 확인한 경우에는 `예약 완료`로 표시하고, 실제 적용으로 처리해 30초 안내를 닫지 않습니다.

**LMU**의 기존 ABS·TC·브레이크 바이어스 추천은 유지합니다. 새 ARB·윙·공기압·덕트 추천은 현재 MFD 선택값·조절 제한·적용 확인이 없어 활성화하지 않았습니다. iRacing 지원표를 LMU에 대입하지 않습니다. iRacing 덕트도 Black Box 조절 근거가 확인되지 않았습니다. 연료·타이어·VE는 기존 전략 안내를 사용하며 이번 설정 비교와 합치지 않았습니다.

## 설정 안내 음성

기존 ABS·TC·브레이크 바이어스 여섯 문장은 로컬 파일과 공개 음성팩 2.1.2의 해시가 일치합니다. 사용자 승인으로 아래 14문장(382자)을 합성해 이 PC의 앱 음성 캐시에 저장했습니다. 주행 코치 Algenib 목소리이며 총 217,056바이트입니다. 공개 음성팩에는 아직 올리지 않았습니다.

현재 ARB 기능에 필요한 네 문장:

- 앞 안티롤바를 조금 부드럽게 시험해 보세요.
- 뒤 안티롤바를 조금 부드럽게 시험해 보세요.
- 다음 피트에서 앞 안티롤바를 조금 부드럽게 시험해 보세요.
- 다음 피트에서 뒤 안티롤바를 조금 부드럽게 시험해 보세요.

실제 장착값 연결 이후 사용할 후보 열 문장:

- 다음 피트에서 리어 윙을 낮춰 보세요.
- 다음 피트에서 리어 윙을 높여 보세요.
- 다음 피트에서 왼쪽 앞 공기압을 조금 낮춰 보세요.
- 다음 피트에서 왼쪽 앞 공기압을 조금 높여 보세요.
- 다음 피트에서 오른쪽 앞 공기압을 조금 낮춰 보세요.
- 다음 피트에서 오른쪽 앞 공기압을 조금 높여 보세요.
- 다음 피트에서 왼쪽 뒤 공기압을 조금 낮춰 보세요.
- 다음 피트에서 왼쪽 뒤 공기압을 조금 높여 보세요.
- 다음 피트에서 오른쪽 뒤 공기압을 조금 낮춰 보세요.
- 다음 피트에서 오른쪽 뒤 공기압을 조금 높여 보세요.

음성에 설정 숫자를 넣지 않았습니다. 승인한 문장은 음성 준비 목록에 등록했습니다. 이 PC에서는 저장된 파일을 재사용하며, 주행 중 파일이 없어져도 자동 과금 합성하지 않습니다. 윙·공기압 음원은 준비했지만 실제 장착값을 확인하기 전에는 해당 자동 추천이 나오지 않습니다.

## 경기 순위 변화 그래프

레이스·인듀런스 경기의 주행 파일을 고르면 상단 작업 메뉴 오른쪽, `코너 번호 확인` 왼쪽에 `순위 변화` 버튼이 나타납니다. 누르면 그 아래 분석 영역 전체를 순위 그래프로 바꿉니다. 같은 버튼이나 `분석으로 돌아가기`로 기존 화면에 돌아갑니다.

- 혼합 클래스 경기에서도 **내 클래스 차량만** 표시합니다. 세로축은 클래스 순위이며 1위가 위쪽입니다.
- 가로축은 기록 시작부터의 경과 시간입니다. 끝까지 기록하지 못했다면 기록된 구간만 표시하며 출발·최종 순위를 추정하지 않습니다.
- **왼쪽 버튼을 누른 채 오른쪽으로 드래그**하면 선택 구간을 확대합니다. 왼쪽으로 드래그하면 이전 범위로 축소합니다.
- 마우스 휠은 순위를 위아래로 스크롤합니다. 좌우 이동은 아래 막대를 왼쪽 버튼으로 잡아 움직입니다. 막대에 초점을 두고 좌우 화살표로도 이동할 수 있습니다.
- 선을 가리키거나 차량 목록을 누르면 해당 차량을 강조합니다. 내 차량은 `나` 표시로 구분합니다.

IBT에 순위 채널이 있으면 직접 읽습니다. LMU 등 순위 채널이 없는 파일은 이 PC에 저장된 경기 타이밍 기록을 사용하며, 차량·트랙·게임과 원본 기록 시각이 일치해야 연결합니다. 예전 타이밍 기록은 같은 경기의 음성 전달 이력 두 시점도 대조합니다. 다른 경기이거나 기록이 없으면 안내만 표시합니다. 클래스 미확인·누락·연결 단절 구간을 추정해 이어 그리지 않습니다. 순위 그래프를 여는 일로 로그를 전송하지 않습니다.

기존 로컬 경기 타이밍 기록은 최대 30개를 보관하므로 오래된 파일에 별도 순위 채널이 없으면 그래프를 보지 못할 수 있습니다. 긴 경기는 표시 표본 수를 제한하므로 표본 사이의 짧은 순위 변동이 생략될 수 있습니다.

## 완주 결과

레이스에서 본인 차량의 완주를 확인한 뒤 그래프·페달·기어를 모두 가리고 경기 결과를 표시합니다. 선두의 체커나 남은 시간만으로 본인의 완주를 판정하지 않습니다. 연습·퀄리·리플레이에는 레이스 포디움이 나오지 않습니다.

- 출발 → 완주 클래스 순위와 순위 변화. 출발 전 그리드를 관측하지 못했다면 출발 순위는 `—`입니다.
- 이번 레이스의 개인 베스트 랩 시간.
- 같은 클래스 참가자의 개인 베스트 랩 중 내 기록의 순위. 밀리초가 같으면 공동 순위를 유지합니다.
- 같은 클래스 최고 랩과 차이. 전원 기록을 확인하지 못하면 확인한 차량 수와 `확인된 최고 랩`으로 범위를 밝힙니다.

최종 클래스 1~3위는 순위별 트로피·월계수·숫자를 약 6초 보여준 후 결과를 유지합니다. 그 외 순위는 바로 결과를 보여줍니다. 잠정 결과는 잠정으로 표시하고 최종 결과 전에는 포디움 축하를 보류합니다. DNF·실격도 별도 상태로 표시합니다. 차량에서 내려도 같은 경기 결과는 남으며 다른 세션·게임·차량으로 넘어가면 사라집니다.

축하는 같은 실행의 같은 경기에서 한 번만 재생합니다. Windows의 애니메이션 끄기 설정에서는 정적인 축하 화면으로 대체합니다. 트로피 자산은 사용자가 승인한 imagegen 제작 시안의 금·은·동 세 형태를 사용하며 기존 연습 성공 축하는 유지합니다.
