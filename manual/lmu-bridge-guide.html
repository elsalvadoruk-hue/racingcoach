LMU 버전이 맞지 않을 때 브리지 사용법

2.0.1부터는 앱에 실시간 브리지가 포함됩니다. 설치된 LMU SDK와 맞으면 빌드 도구 없이 바로 씁니다. 설정 → LMU 실시간 연결에서 준비됨이면 아래 설치 과정은 건너뛰고, LMU에서 차에 탄 뒤 음성 코치의 스포터·피트월을 켜세요.

직접 빌드는 SDK가 맞지 않을 때만 설치 시간·용량은 PC와 선택 항목에 따라 다릅니다

LMU가 패치될 때마다 다시 해야 하나요?

LMU 패치마다 브리지를 빌드하거나 주행 코치를 새 버전으로 올릴 필요는 없습니다. 앱은 설치된 SDK 헤더와 브리지가 맞는지 확인합니다. 헤더 구성이 그대로면 기존 브리지를 계속 씁니다.

빌드 필요 또는 다시 빌드 필요가 나와도 주행 코치 버전을 올리지 않고 아래 5단계로 직접 빌드해서 해결할 수 있습니다. 편하게 연결하려면 먼저 앱 업데이트를 확인하세요. 현재 SDK에 맞는 브리지가 포함된 버전이면 빌드 없이 바로 준비됩니다. 새 앱 버전은 미리 빌드된 파일을 받는 편의 기능이며 직접 빌드의 필수 조건은 아닙니다.

SDK 헤더는 LMU 설치 폴더의 공유 메모리 자료형 정의 파일입니다. 포함된 브리지를 쓸 때도 호환 여부를 확인할 수 있도록 LMU 설치 파일이 필요합니다.

VS Code가 아닙니다. 필요한 것은 Visual Studio Build Tools(마이크로소프트의 무료 C++ 빌드 도구)입니다. VS Code나 Visual Studio 본체는 깔지 않아도 됩니다. 주행 분석(기록 보기)만 쓸 거라면 이 과정 전체가 필요 없습니다.

1빌드 도구 받기

  1. Microsoft C++ Build Tools 페이지를 엽니다.
  2. Build Tools 다운로드 버튼을 누릅니다.
  3. 받은 vs_BuildTools.exe를 실행합니다.

5"준비됨"이 뜨면 끝

  1. 표시가 준비됨으로 바뀌고 빌드 버튼이 사라지면 성공입니다.
  2. 이제 LMU를 켜고 차에 탄 뒤 음성 코치에서 스포터·피트월을 켜 실제 연결을 확인합니다.

“준비됨”은 브리지를 사용할 수 있다는 뜻입니다. 실제 데이터는 차에 탄 상태와 세션에 따라 들어옵니다. 수신되지 않으면 차에 타고 트랙에 나간 뒤 연결 상태를 확인하세요.

준비됨사용할 수 있는 브리지가 있습니다. 빌드 도구 설치나 직접 빌드 없이 LMU에서 차에 탄 뒤 스포터·피트월을 켜 확인합니다.
빌드 필요현재 SDK에 맞는 브리지가 없습니다. 앱 업데이트를 먼저 확인하고, 맞는 브리지가 없다면 위 5단계로 직접 빌드합니다.
다시 빌드 필요SDK 헤더 등이 기존 브리지와 달라졌습니다. 앱 업데이트를 확인하거나 4단계에서 다시 빌드합니다. C++ 빌드 도구가 이미 설치돼 있으면 다시 설치하지 않아도 됩니다.
LMU SDK 없음SDK 헤더를 찾지 못했습니다. Steam에서 LMU 설치와 게임 파일 무결성을 확인합니다. 기본 위치는 Le Mans Ultimate/Support/SharedMemoryInterface이며 다른 Steam 라이브러리도 자동으로 찾습니다. SharedMemoryInterface.hpp·InternalsPlugin.hpp·PluginObjects.hpp 세 파일이 있는지 확인하세요. 직접 지정해야 한다면 Windows에서 “환경 변수”를 검색해 환경 변수 편집 화면을 열고 사용자 변수 LMU_SDK_DIR를 추가합니다. 값은 이 세 파일이 들어 있는 폴더의 전체 경로로 넣고 앱을 완전히 종료한 뒤 다시 실행하세요. 이후 상태 새로고침을 누릅니다.
빌드 중 오류 문장대부분 빌드 도구가 없거나 "C++를 사용한 데스크톱 개발"이 빠진 경우입니다. 2단계를 다시 확인하고, PC를 한 번 재시작한 뒤 다시 누르세요.
