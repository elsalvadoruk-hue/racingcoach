LMU 실시간 연결

LMU를 실행하고 차에 탄 뒤 스포터나 피트월을 켜세요. 연결 파일은 앱이 자동으로 준비합니다. 추가 개발 도구를 설치하거나 파일을 직접 만들 필요가 없습니다.

주행 코치 2.0.2 이상추가 연결 파일을 처음 받을 때만 인터넷 필요

1LMU를 고르세요

실행.bat으로 앱을 켜고 상단에서 LMU를 고릅니다. 게임을 실행하고 차에 탑니다.

iRacing과 LMU에서 같은 스포터·피트월·F8 질문·오버레이를 사용합니다.

localhost:24157

게임에서 차에 타세요.

2스포터나 피트월을 켜세요

앱의 음성 코치에서 필요한 안내를 켭니다. 연결 파일이 이미 준비돼 있으면 바로 사용합니다.

다른 연결 파일이 필요하면 앱이 백그라운드에서 받습니다. 준비되는 동안 잠시 기다리세요.

3상태가 궁금하면 설정에서 확인하세요

설정 → LMU 실시간 연결에 준비 상태가 나옵니다. 받기에 실패했다면 인터넷을 확인하고 실시간 연결을 눌러 다시 시도합니다.

“준비됨”은 연결 파일이 확인됐다는 뜻입니다. 실제 주행 데이터는 LMU에서 차에 탄 뒤 들어옵니다.

준비됨LMU에서 차에 탄 뒤 스포터나 피트월을 켜세요. 추가 파일이 필요하지 않으면 인터넷 없이 씁니다.
연결 준비 중연결 파일을 자동으로 받는 중입니다. 잠시 기다리세요.
호환 연결 파일 준비 중새 LMU 버전용 파일이 아직 제공되지 않았습니다. 앱이 5분마다 다시 확인하고 준비되면 연결합니다. 설정에서 “실시간 연결”으로 다시 확인해도 됩니다.
연결 파일 받기 실패인터넷 연결을 확인하고 “실시간 연결”을 눌러 다시 시도하세요. 이미 확인한 연결 파일은 계속 사용할 수 있습니다.
LMU 설치 확인 필요Steam에서 LMU 설치와 게임 파일 무결성을 확인한 뒤 앱을 다시 실행하세요. 다른 Steam 라이브러리도 자동으로 찾습니다.

LMU 패치마다 앱을 업데이트해야 하나요?

아닙니다. 연결 방식이 그대로면 기존 파일을 계속 사용합니다. 다른 버전용 연결 파일만 필요하면 앱이 자동으로 받습니다.

연결 방식 자체가 바뀌어 앱 수정도 필요한 경우에는 앱 업데이트가 필요합니다. 아직 지원되지 않는 데이터를 추측해 읽지는 않습니다.

Google 키와 마이크 권한은 F8 음성 질문을 쓸 때 별도로 필요합니다. 연결 파일 다운로드에는 Google 키나 음성 합성이 필요 없습니다.
