# 개인 주행 학습

비슷한 조건에서 **내가 어떻게 달렸을 때 반복해서 좋았는지** 찾습니다. 새 학습은 현재 iRacing에서 지원합니다.

| 확인하는 것 | 비교 방법 |
| --- | --- |
| 제동·가속 | 제동 시작, 브레이크 해제, 가속 시작 시점과 구간 시간·마지막 속도 |
| BB·ABS·TC | 한 설정만 다른 통과의 시간·탈출 속도·조향 수정·가속 재리프트. 시간 이득 / 안정성 이득 / 결론 보류 |
| 연속 코너 | 최대 세 코너와 뒤쪽 구간 전체. 첫 진입을 양보한 것이 전체에서도 이득인지 확인 |
| 연석·충격 | 수직 가속도와 서스펜션 움직임으로 측정한 충격과 이후 결과. 충격 때 연석 신호가 있어야 연석으로 구분 |

음성 코치의 **개인 주행 학습** 카드와 저장 파일의 **주행 요약 → 개인 주행 학습**에서 확인합니다.

실시간 학습은 기존 주행 파일 분석으로 해당 차량·트랙의 코너 구간이 준비돼 있어야 시작합니다. 구간 정의가 없으면 먼저 주행 파일을 분석해 주세요.

## 결과가 나오는 조건

- 같은 차량·트랙·레이아웃·측정 구간, 연료 차이 6L 이내·노면 온도 차이 3°C 이내·같은 젖음과 컴파운드를 비교합니다. 연료는 통과 쌍마다 맞춥니다.
- 같은 주행의 다른 랩, 또는 같은 셋업 지문이 확인된 다른 주행을 비교합니다. 같은 통과를 다시 읽어도 횟수는 늘지 않습니다. 실시간과 IBT는 따로 평가합니다.
- 최소 4쌍, 즉 8회 이상의 독립 통과가 필요합니다. 앞쪽에서 찾은 방향이 뒤쪽 최소 2쌍에서도 측정 오차·편차를 넘어 반복돼야 합니다.
- 빨라도 마지막 속도나 안정성이 나빠지면 추천을 보류합니다. 현재 랩을 근거로 그 랩에 추천하지 않습니다.
- 인시던트·피트·리플레이·주변 차량·기록 공백은 제외합니다. 사고 랩에서도 분리된 정상 구간은 사용할 수 있습니다.

**주변 차량이나 필수 채널을 모르면 보류합니다.** 일반 IBT는 주변 차량 자료가 없어 횟수만 표시될 수 있습니다. LMU는 현재 새 학습을 보류합니다. 시작선을 가로지르는 코너는 이번 학습에서 제외합니다.

## 음성 안내

상황별 음성 안내에서 **개인 제동·가속 학습 / 연속 코너 연결 학습 / 연석·충격 통과 학습**을 각각 선택합니다. 기존 ‘중요한 것만’ 설정은 새 일반 안내를 기본으로 끌 수 있으므로 원하는 항목을 직접 켜 주세요.

현재 조건이 맞고 바로 다음 코너 진입 전에 말할 시간이 충분한 직선에서 랩당 한 번 안내합니다. 대기 중 조건이 바뀌거나 안내를 끄면 취소합니다. 다시 켜도 지난 안내를 뒤늦게 말하지 않습니다.

기본 24개·짧은 24개의 학습 음성을 지원합니다. 현재 코치의 음성 길이·음성팩 선택을 따르며 선택한 팩에 문장이 없으면 안내를 보류합니다. 주행 중 누락 음원을 새로 합성하지 않습니다. BB·ABS·TC 비교와 연석을 더 사용한 이득은 화면으로 표시합니다.

## 결과의 의미와 보관

반복 관측 결과이며 타이어 온도·압력·마모까지 통제한 최적값이나 인과관계 확정은 아닙니다. G·ABS 개입량만으로 그립을 판정하지 않습니다. 기존 셋업 A/B 확정 근거로 자동 편입하지 않으며 게임 설정을 자동 변경하지 않습니다.

연속 구간과 개별 코너의 시간은 겹치므로 합산하지 마세요. 숫자가 크다고 ABS·TC가 반드시 강한 것도 아닙니다. 실제 관측한 값끼리 비교합니다.

데이터 폴더의 `driving-learning.json`에 숫자·코드 요약만 최대 1,800회/4MB/30일 보관하고 한 구간의 최근 최대 120회를 평가합니다. 화면·자유 문장·운전자 이름·파일 경로를 저장하지 않습니다. 공유·배포 파일에는 개인 기록을 넣지 않습니다.

로컬 개발본입니다. 앱과 검은 실행창을 완전히 종료한 뒤 다시 실행하면 적용됩니다. 새 실주행·사람의 음성 청취 확인은 별도로 필요합니다.
