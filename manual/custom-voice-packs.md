# 설치한 음성팩을 역할별로 사용하기

이 문서는 기본 짧은 무전과 2.3.0 이상에서 지원하는 외부 커스텀 음성팩 안내입니다. 음성 제작 프로그램 Voice Studio와 외부 커스텀팩은 별도 파일입니다.

## 2.5.0 준비본: 기본 / 짧은 무전

스포터와 피트월에서 **음성 길이**를 각각 선택합니다. 목소리는 기존 이름으로 한 번만 표시하며, 짧은 팩을 별도 목소리로 나열하지 않습니다. 스포터는 Fenrir·Algieba·Schedar·Aoede 중 선택한 목소리에 맞춰 전환하고, 피트월 길이는 코치·레이스·전략 세 역할에 함께 적용됩니다. 두 영역은 서로 독립적이고 게임별 선택도 기존 방식으로 저장됩니다.

기본 짧은 무전은 **설정 → 업데이트 → 빠진 음성 받기**로 받습니다. 따로 ZIP을 설치할 필요가 없습니다. 다운로드가 끝나면 목록이 갱신됩니다. 스포터·자동 보고를 중지하고 해당 영역의 **짧은 무전**을 선택하세요. 다운로드가 덜 끝났거나 별도 커스텀 목소리를 선택한 경우 짧은 선택이 비활성화됩니다. 기본으로 돌아가도 스포터 목소리는 유지됩니다.

짧은 무전은 바뀐 문장만 추가하고 포메이션·숫자·기존 짧은 좌우·오벌 안내는 준비된 기본 음원을 재사용합니다. 양쪽 모두 없는 음원을 새로 유료 합성하지 않습니다. 먼저 받은 전체 1.0.0·길이 선택용 1.1.0 팩도 계속 인식하며, 기본 짧은 무전 2.5.0을 받으면 새 선택 때 우선 연결합니다. 외부 팩과 기본 짧은 무전은 관리 목록을 구분합니다. 기본 짧은 무전은 음성 길이를 **기본**으로 바꿔 해제합니다.

현재 2.5.0은 로컬 준비본이며 음성 다운로드 파일도 아직 공개하지 않았습니다. 공개 2.4.5 ZIP에는 이 기능이 포함되지 않습니다. 실제 배포 때 앱과 음성 파일을 함께 공개해야 위 다운로드를 사용할 수 있습니다.

## 다른 커스텀 목소리 설치

1. Voice Studio에서 원하는 역할의 음성을 생성·검수하고 `.rcvoice.zip`을 저장합니다. 스포터나 피트월 한 역할만 만들어도 됩니다.
2. 음성 코치 → **음성팩 설치·관리 → ZIP 파일 설치**를 누릅니다. 경로로 폴더를 설치할 수도 있습니다. 파일 전송 → 음성 검사 → 파일 복사 → 최종 확인 순서로 진행 상태·실제 처리 개수·경과 시간을 표시합니다. 전송 100%는 설치 완료가 아니며 검증 후 자신의 관리 폴더에 복사합니다. 검사 중 전체 개수를 아직 모르면 완료 개수만 표시합니다. 새로고침해도 서버에서 진행 중인 작업을 다시 표시하며, 실패 원인을 확인한 뒤 재시도할 수 있습니다.
3. 스포터의 **목소리·반복 설정** 또는 피트월 세 역할의 **목소리**에서 설치한 팩을 선택합니다. 역할별로 기본 목소리와 섞을 수 있습니다. 팩에 해당 역할이 있어야 그 목록에 표시됩니다. 처음 적용할 때 설치 파일을 다시 확인하므로 큰 팩은 시간이 걸립니다. 선택칸이 잠긴 동안 **목소리 적용 중**에서 실제 확인 개수·경과 시간을 볼 수 있으며, 완료되면 다시 선택할 수 있습니다.
4. 없는 문장은 준비된 기본 음성으로 보완합니다. 기본 파일은 설정 → 업데이트 → **빠진 음성 받기**로 준비합니다. 커스텀 누락 때문에 유료 합성을 자동 요청하지 않습니다. 양쪽에 없으면 안내를 생략합니다. 스포터의 필수 호출이 양쪽 모두에 없으면 켜기를 막고 준비할 상황을 알려줍니다.
5. **적용 해제·삭제**에서 적용만 해제하거나 설치한 로컬 파일까지 삭제할 수 있습니다. 두 게임의 역할 선택을 정리합니다. 직접 받은 원본 ZIP·폴더와 Studio 프로젝트는 보존합니다. 스포터·자동 보고를 끈 뒤 바꾸세요.

앱 업데이트로 새 문장이 생기면 설치팩에 추가 제작 알림이 나옵니다. **추가 제작 목록 저장**으로 JSON을 받아 Studio의 원래 프로젝트 또는 개인 제작설정을 연 뒤 넣습니다. 새 대본만 추가·생성·검수하고 팩 버전을 올려 설치하세요. 새 버전은 각 역할에서 직접 선택합니다. 원래 일부만 제작한 문장은 업데이트 신규분으로 세지 않습니다. 제작 당시 목록이 없는 구형/시험팩은 신규분을 자동 판정하지 않습니다.

새 manifest v3의 `targets`는 담긴 역할과 일치해야 합니다. 선택적 `catalogBaseline`은 역할별 전체 원문 `(role,sourceText)`의 SHA256 목록이며 로컬 경로를 포함하지 않습니다. 원문 연결은 정확히 일치해야 하고 숫자를 새로 조립하지 않습니다. 기존 v1 WAV·v2 Opus 팩도 지원합니다. Opus는 실제 디코딩까지 검사하며 설치/미리듣기는 선택을 바꾸지 않습니다. AI 자유 답변은 별도 음성입니다.
