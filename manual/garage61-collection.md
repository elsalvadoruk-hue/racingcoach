# Garage61 팀 가입과 가져올 데이터 선택

## 다른 드라이버 기록을 받으려면 팀에 먼저 가입하세요

> **Bloops처럼 회원이 많은 팀에 가입하는 것을 권장합니다.** 가입할 팀을 잘 모르겠다면 가입하기 쉬운 **Bloops**가 편합니다. Garage61 기본 API는 **내 기록과 가입한 팀의 팀원 기록**을 조회하므로, 토큰만 등록하고 팀에 가입하지 않으면 내 기록만 보일 수 있습니다.

1. Garage61에 로그인하고 **Teams → Join a team**을 엽니다.
2. **Bloops**를 검색해 가입하고, **My teams**에 나타나는지 확인합니다. 가입 승인이 필요한 경우에는 승인을 기다립니다.
3. **driving_data** 권한을 포함한 개인 API 토큰을 앱의 **설정 → 설치 설정 → Garage61 개인 API 토큰**에 저장합니다. 이미 유효한 토큰을 등록했다면 팀 가입 때문에 다시 발급할 필요는 없습니다.
4. 앱의 **비교 변경** 창을 다시 열어 수집 상태를 확인합니다. **Garage61 다시 확인**은 상태를 다시 조회하며, 표시된 재수집 대기 시간을 해제하지 않습니다.

**‘토큰 등록됨’인데 내 기록만 보이면 팀 가입 여부부터 확인하세요.** 가입한 팀원도 텔레메트리를 공유해야 하며, 같은 차량·트랙·레이아웃과 선택한 수집 방식에 맞는 기록이 있어야 가져올 수 있습니다. 팀 가입만으로 모든 상위 기록이 제공되는 것은 아닙니다. API 앱을 등록한 팀과 다른 팀에 가입해도 토큰 사용자의 가입 팀과 공유 권한에 따라 기록을 조회할 수 있습니다.

기본 조회 범위는 [Garage61 공식 API 명세](https://garage61.net/api/openapi/v1.json)의 랩 검색 제한을 따릅니다. 전체 공개 기록 검색은 별도 승인된 앱에서 허용될 수 있습니다.

## 토큰 없이 Garage61 웹에서 랩 가져오기

API 토큰을 발급하기 어렵다면 Garage61 웹에서 직접 내려받은 랩도 비교 기준으로 쓸 수 있습니다. 웹에서는 무료 계정으로도 공개된 랩을 볼 수 있습니다.

1. **비교 변경** 창에서 **Garage61 웹에서 랩 가져오기**를 펼치고 **Garage61에서 랩 찾기**를 누릅니다.
2. 기본 브라우저에서 Garage61에 로그인하고, 지금 주행과 같은 차량·트랙·레이아웃의 랩을 찾아 랩 메뉴의 **Export to CSV**로 내려받습니다.
3. 앱으로 돌아오면 다운로드 폴더의 새 Garage61 CSV가 목록에 나타납니다. **가져오기**를 누르면 그 랩이 **Garage61 대표 기준**으로 선택됩니다. 다른 폴더에 저장했다면 **CSV 파일 직접 선택…**을 사용합니다.

앱은 Garage61 사이트를 대신 조작하지 않습니다. 사용자가 내려받은 파일만 확인해 데이터 폴더의 Garage61 기준 폴더에 복사본을 보관하며 원본은 그대로 둡니다. 같은 랩이 이미 있으면 다시 복사하지 않습니다. 웹에서 받은 CSV에는 날씨·연료 같은 조건 정보가 없어 조건 비교는 확인 필요로 표시되고, 차량·트랙·레이아웃이 다른 랩은 비교하지 않습니다. 토큰이 없으면 자동 수집과 자동 추천은 하지 않고 직접 고른 랩만 사용합니다. 토큰이 있으면 직접 받은 랩도 다른 랩과 같은 규칙으로 순위를 매깁니다. **가장 빠른 데이터** 방식에서는 랩타임으로만 비교하므로 직접 받은 랩도 똑같이 경쟁하고, **조건에 맞는 데이터** 방식에서는 조건 정보가 없어 조건이 확인된 랩보다 뒤에 놓입니다.

## 가져올 데이터 선택

설정 → **Garage61 기준·수집 → 가져올 데이터**에서 선택합니다.

| 선택 | 가져오는 기록 |
| --- | --- |
| **조건에 맞는 데이터** (기본) | 내 주행과 날씨·연료 등의 조건이 비슷한 기록을 우선합니다. 기존 방식입니다. |
| **가장 빠른 데이터** | 같은 차량·트랙·레이아웃의 공개 후보를 랩타임이 빠른 순서로 가져옵니다. 날씨·연료·Fixed/Open 조건은 다를 수 있습니다. |

선택하면 자동 저장되고 다음 자동 수집과 데이터 보충·강제 수집에 적용됩니다. 수집 중에는 변경할 수 없습니다. 선택을 바꾼 뒤 바로 받고 싶으면 **데이터 보충**을 누르세요. 방식별 수집 이력과 재수집 대기 시간을 구분하며, 내려받은 CSV는 재사용합니다.

기준 목록과 자동 추천도 선택한 방식의 순서로 보여 줍니다. 드라이버별 기록을 우선하며 공개 API 후보 최대 1,000개와 기존 검색 기간 안에서 고릅니다. 모든 기간의 세계 최고 기록을 보장하는 기능은 아닙니다. 토큰 권한·비공개 설정 때문에 가져올 수 없는 기록은 제외합니다.

이미 적용한 비교 기준과 진행 중인 셋업 실험은 자동으로 바꾸지 않습니다. 새 기준을 확인한 뒤 적용하세요. 빠른 기록을 가져와도 셋업 효과를 판단하는 조건 검증은 유지하며, 조건이 다르다는 사실을 셋업 이득으로 해석하지 않습니다.

Garage61 기준은 iRacing에서 사용합니다. LMU에는 적용되지 않습니다.
