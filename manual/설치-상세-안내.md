# 설치 상세 안내

일반 설치는 [README의 빠른 시작](../README.md#getting-started)을 따르세요. 최신 설치본은 [공식 Releases](https://github.com/elsalvadoruk-hue/racingcoach/releases/latest)의 `racingcoach-setup-*.zip`입니다.

## 기존 사용자 업데이트

1.4.2 이상에서는 앱의 **설정 → 업데이트**에서 **업데이트 받기 → 지금 다시 시작해서 적용**을 선택합니다. 기록·설정·키·토큰·음성·내장 Python은 보존합니다. 처음 설치용 setup ZIP을 기존 폴더에 다시 풀 필요는 없습니다.

1.4.1 이하에서는 다음 과정을 한 번 수행합니다.

1. 앱과 실행 창을 닫고 기존 프로그램 폴더를 복사해 백업합니다.
2. [소스 ZIP](https://github.com/elsalvadoruk-hue/racingcoach/archive/refs/heads/main.zip)을 임시 위치에 풉니다. 새 폴더 안의 `실행.bat`, `src`, `scripts` 등 **내용물**을 기존 프로그램 폴더에 덮어씁니다. 새 폴더 자체를 기존 폴더 안에 넣지 마세요.
3. 기존 `data`와 개인 설정은 삭제하지 않습니다. **설치.bat**을 다시 실행해 패키지와 화면 빌드를 갱신합니다. 소스 ZIP은 Python과 Node.js가 필요합니다.
4. **실행.bat**으로 켠 뒤 **설정 → 업데이트 → 빠진 음성 받기**를 누릅니다. 1.4.0 이전 음성이 남아 있으면 **이전 버전 음성 정리**로 정리합니다. 데이터 폴더나 음성 폴더 전체를 직접 지우지 마세요.

Git으로 받은 폴더에서는 앱이 프로그램을 덮어쓰지 않습니다. 로컬 변경을 먼저 보존하고 `git pull --ff-only` 후 `설치.bat`을 실행합니다. 음성 받기는 앱에서 그대로 사용할 수 있습니다.

## 음성을 직접 받을 때

앱의 **빠진 음성 받기**를 우선 사용하세요. 직접 받기는 GitHub 다운로드가 막힌 네트워크 등을 위한 예비 방법입니다.

1. 앱과 실행 창을 닫습니다.
2. [공식 Google Drive 공유 폴더](https://drive.google.com/drive/folders/1MPvrKi4Zw9fInU5f84mCwe_Bt0uhW631?usp=sharing)의 전체 음성팩을 받습니다. Drive에 있는 2.0.0 전체팩은 기존 음성용이며, 2.1.0 추가 음성은 앱에서 따로 받습니다.
3. ZIP의 `data` 폴더가 프로그램의 `data` 폴더와 합쳐지도록 풉니다. 정상 위치는 `프로그램 폴더/data/radio_audio/`, `프로그램 폴더/data/spotter_audio/`입니다. `data/data/`처럼 중첩하지 마세요.
4. 데이터 위치를 따로 지정했다면 **설정 → 설치 설정**에 표시된 폴더에 `radio_audio`와 `spotter_audio`를 합칩니다.
5. 앱을 다시 켜고 **설정 → 업데이트 → 빠진 음성 받기**로 현재 버전에 필요한 나머지 파일을 확인합니다.

`data`의 DB, `settings.json`, 키·토큰, 코너 번호, 피트·경기 기록은 삭제하지 마세요. 개인 질문·AI 답변 음성과 녹음 원음은 디스크 음성 캐시 대상이 아닙니다.

## 음성·장치 설정

**음성 코치 → 음성·장치 세부 설정**에서 장치·볼륨·속도를 고릅니다. 스포터와 피트월의 기본 속도는 각각 1.15배, 여러 문장 안내는 1.30배이며 1.0~1.4배를 선택할 수 있습니다. 여러 문장 속도는 담당 속도와 곱하지 않습니다. 포메이션 브리핑은 1.15배 고정입니다. 변경한 속도는 다음 안내부터 적용하며 음높이는 유지합니다.

볼륨은 0~130%이며 기본은 100%입니다. 100% 초과는 증폭 구간이므로 찌그러지면 낮추세요. 게임 소리에 묻히면 Windows 볼륨 믹서에서 게임 소리를 조절할 수 있습니다.

Bluetooth 장치가 잠시 끊겨도 저장한 선택을 유지합니다. 사용할 수 없으면 임시로 Windows 기본 출력으로 재생하며, 장치가 돌아오면 다음 안내부터 복귀합니다. 앱은 Windows나 게임의 오디오 설정을 바꾸지 않습니다. 통화용 Hands-Free보다 스테레오 출력을 권장합니다.

화면 주소는 **http://localhost:24157**로 유지하세요. 다른 주소에서는 브라우저에 저장한 장치·진행 중 실험·설정이 보이지 않을 수 있습니다.
