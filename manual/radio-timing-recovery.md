# 랩타임 안내와 음성 정지 복구

## 10월30일 로컬 개선본 · 미공개

앱과 검은 실행창을 완전히 종료한 뒤 다시 실행하면 적용됩니다. 새 음성은 제작하지 않았으며 버전은2.4.3입니다.

첫 랩에도 위치가 유효하면 앞뒤 차량의 통과 이력을 모읍니다. 스포터와 피트월은 같은 지점의 통과 시간 차를 우선 사용합니다. 이력이 부족하면 접근 안내를 보류하며 클래스 예상 랩타임만으로 접근을 확정하지 않습니다. LMU의 직접 간격은 대상이 확인되는 경우에 비교 자료로만 사용합니다. 원본 scoring의 보관/추정 위치를 구분하고 속도 결측이나 긴 관측 공백에는 위치를 미확인으로 둡니다.

코너를 통과한 측정과 단독 기준을 구분합니다. 교통 동반·교통 미확인 구간은 측정에 맥락을 남기고 단독 기준 갱신과 비교 조언에서는 제외합니다. 앞차가 느려진 원인이라고 단정하지 않습니다. LMU의 새 충돌 사건과 공식 랩 판정도 따로 전달합니다. 일반 과열·부품 탈락은 냉각수 전용 경고나 선택 수리 가능 신호로 바꾸지 않습니다.

피트 이동 손실 학습은 코션·사고·견인·수리·트랙 위 대기·표본 공백을 제외합니다. 타이어 작업 규칙을 모르면 동시 작업으로 가정하지 않으며 단일 자동 손실이 없는 경우 복귀 순위 안내를 보류합니다. LMU 피트 상태만으로 작업 완료·수리시간·출발 허가를 판단하지 않습니다.

포메이션 음성은 처음 관측한 출발 위치부터 다음 스타트라인까지 남은 구간에 배분합니다. 설정한 개수는 유지하지만 시간이 부족하거나 다른 무전이 우선하면 일부를 생략합니다. 그린 이후에는 포메이션 후보를 만들지 않습니다.

오버레이의 **포메이션** 탭에서 텍스트 항목을 선택하고 **저장·적용**하세요. 출발 순위·참가 규모는 고정이며 현재 연료·날씨와 지원되는 기록을 순환합니다. 무전 OFF/안내0개·분석/과제 없이도 현재 자료를 표시합니다. iRacing의 SoF·iRating·공식 정렬과 LMU의 바퀴 온도·가상 에너지는 게임별로 구분합니다. 공식 그리드·퀄리 입력이 없으면 확인 중입니다. 현재 순위를 출발 순위로 쓰지 않습니다. 지난 기록과 직접 메모는 같은 게임·차량·트랙·레이아웃만 사용하고, 메모는 원문을 나눠 표시합니다. 수동 포메이션도 그린에서 종료하며 기존 카드/입력 그래프 설정은 보존합니다.

합성 자동 검사·격리 브라우저·실제 Tk 렌더링을 검증했습니다. 새 실제 주행·다른PC·사람 한국어 청취 결과는 아닙니다. 상세 범위: [1030 개선 결과](1030-improvement-plan.md).

2.3.1부터 적용된 동작과 2.4.3의 보완을 함께 설명합니다. iRacing·LMU에 공통으로 적용합니다. 추가 음성은 기본 음성팩 2.4.3에 포함되며 **설정 → 업데이트 → 빠진 음성 받기**로 받습니다.

랩타임은 앱이 랩 완료를 감지하면 준비된 음성으로 바로 안내합니다. 조작이 조용해질 때까지 기다리던 조건과 직전 일반 안내 뒤 대기는 랩타임에 적용하지 않습니다. 완료 감지 후 2초 안에 재생을 시작하지 못하면 생략합니다. 늦게 도착한 게임의 랩타임 값도 이 시간을 늘리지 않습니다. 준비된 필수 음성이 없으면 합성을 기다리지 않고 생략합니다. 추가 문장은 준비된 것만 붙입니다.

좌우 차량이 겹쳐 있거나 기존 교통 정보에서 앞뒤 차량 간격이 0.7초 이내이면 랩타임을 시작하지 않습니다. 2.4.3에서는 일반 자동 보고를 멈추고 랩타임을 먼저 읽습니다. 멈춘 보고는 이후에도 유효하면 기존 재시도 한도 안에서 다시 안내합니다. 긴급 보고·다른 실시간 안내·운전자 질문 답변은 우선하며 그 사이 제한 시간이 지나면 랩타임을 생략합니다. 시작한 랩타임은 2초가 지나도 끝까지 재생하며, 긴급 안내에 끊긴 랩타임은 재개하지 않습니다. 퀄리 랩타임은 순위 집계를 기다리지 않고, 순위는 별도 안내합니다.

게임이 완료 신호나 랩타임 값을 늦게 제공하거나 교통 정보가 부족한 경우에는 실제 결승선 통과 순간과 차이가 생길 수 있습니다. 모든 배틀을 판별한다는 보장은 없으며, 기존 교통·좌우 차량 정보로 판단합니다.

자동 무전의 음성 준비 요청은 최대 8초 또는 해당 안내의 남은 유효시간까지만 기다립니다. 세션·게임·연결이 바뀌면 이전 요청을 취소합니다. 브라우저가 취소에 응답하지 않아도 다음 요청을 막지 않습니다. 취소된 요청의 늦은 응답은 재생하지 않습니다.

2.4.3에서는 재생 시작 전 취소·만료되면 출력장치 연결·효과 준비·브라우저 재생 대기도 해제합니다. 취소 뒤에 시작 지연 오류를 덧붙이거나 늦게 재생하지 않습니다. 이미 시작한 문장은 기존 정책대로 끝까지 읽습니다.

피트박스 50·20·10미터는 짧게 거리만 읽습니다. 더 가까운 거리 안내가 오면 재생 중인 이전 거리 안내를 바꿉니다. 다른 경고나 질문 답변은 기존 우선순위를 따릅니다. 실제 이동·자료 갱신·재생 지연으로 모든 거리를 반드시 들을 수 있다는 보장은 없습니다.

5:00.0~5:59.9·6:00.0~6:09.9의 누락 음성을 기존 문장 조각 방식으로 보충합니다. 스포터 네 기본 목소리와 레이스 엔지니어의 준비 목록에도 포함합니다. 커스텀팩의 기존 누락 처리 정책은 유지합니다. 기본 음성팩 2.4.3에 추가 조각 2,629개와 짧은 피트 거리 12개를 포함했습니다. 기존 오벌 음성 56개도 함께 제공합니다.

출력장치 연결·효과음 준비·재생 시작이 5초 이상 멈추거나, 시작한 음성의 재생 위치가 5초 이상 진행하지 않으면 해당 안내를 종료하고 다음 안내를 다시 시도합니다. 정상 진행하는 긴 음성에는 전체 길이 제한을 두지 않습니다. 오류 이유는 기존 로컬 음성 전달 기록과 브라우저 콘솔에 남깁니다. 장치 자체가 계속 연결되지 않는 경우에는 장치 연결과 출력 설정을 확인해야 합니다.

적용하려면 앱과 검은 실행창을 완전히 종료한 뒤 다시 실행하세요.

## 2.4.0의 외부 로그 후속 개선 (2026-10-27)

퀄리 순위·격차 전체 문장이 준비된 음성 범위를 벗어나면 기존 순위 음성으로 안내합니다. 화면에는 원래 순위와 격차를 유지합니다. 일반 전체 문장은 1~40위·0.1~3.0초, 대체 순위 음성은 1~60위 범위입니다. 범위 판정은 실제로 읽는 소수 첫째 자리 표현을 따릅니다. 공동 기록처럼 격차가 0.0초로 표시되는 경우에도 순위만 읽습니다. 필요한 기본·선택 음성이 없거나 파일이 손상된 경우 이번 음성을 생략하며 자동 합성을 요청하지 않습니다. 퀄리 랩타임과 별도인 기존 순위 안내 시점·설정은 유지합니다.

재생 시작 전 오류는 같은 안내에서 총 3회까지만 시도합니다. 첫 실패 후 0.5초, 두 번째 실패 후 1초를 기다리고 유효시간·연결·주행 조건을 다시 확인합니다. 실패한 렌더 음성은 다시 받으며 새 안내와 안전 경고는 별도로 처리합니다. 세 번 실패하면 해당 안내를 종료합니다. 이미 시작한 안내의 기존 중단·재개 정책은 유지합니다. 실제 파일·코덱·장치 중 최초 오류 원인을 확정하는 기능은 아닙니다.

연결 대기 음성은 다른 음성이 재생 중이면 생략하고 화면 상태로 표시합니다. 차량에서 내리거나 연결이 끝나도 이미 시작한 경기 결과 문장은 끝까지 들을 수 있습니다. 생략한 연결 대기 음성을 새 세션에서 뒤늦게 재생하지 않습니다. 실제 좌우 차량 등 안전 경고는 여전히 먼저 말할 수 있으며, 사용자의 무전 끄기·게임 전환·장치 변경은 기존 동작을 따릅니다.

## 2.3.2의 로컬 진단 보완

음성 기록과 독립적으로 주행 연결 상태를 보관합니다. 별도 작업이 2초마다 상태를 확인하고 변화가 있거나 정상 수집 중 30초가 지나면 저장합니다. 최근 64개 주행과 각 주행의 최근 128개 상태만 유지하며 오래된 상태가 생략됐다는 개수도 남깁니다. 이 기록으로 실제 음성이 들렸는지나 정확한 연결 단절 순간까지 확정할 수는 없습니다.

로그 파일 받기에는 해당 주행의 상태 기록도 포함됩니다. 안내가 0건인 주행도 목록에서 찾을 수 있고 마지막 무전 이후의 기록을 확인할 수 있습니다. 무전의 취소·만료 등 전달 결과에는 접수 당시 최신 상태를 별도 표시하며, 이를 원래 안내 판단 순간의 상태로 해석하지 않습니다. 이전 세션의 늦은 결과에는 현재 세션의 주행값을 붙이지 않습니다.

기록은 로컬에 저장하며 마이크 내용·녹음·키·개인 설정을 추가 수집하지 않습니다. 기존 자동 보내기 동의와 전송 조건은 그대로입니다. 전송 한도가 부족하면 추가 상태 기록부터 제외하고, 용량이 남으면 기존 교통 자료를 보존하면서 원시 코너 묶음을 최대 3개까지 추가합니다.

테스트·연습에서는 레이스 출발 문구를 생략합니다. LMU 부분 기록은 트랙 전체 길이를 확인할 수 없다는 안내와 함께 코스 거리 비교를 보류합니다. 실측 조향이 없는 차량의 거동 판정 조건은 그대로 유지합니다.
