## 짧은 무전 청취·선택 도구

2.5.6의 앱 업데이트를 적용한 뒤 **설정 → 업데이트 → 빠진 음성 받기**로 승인 음원을 받으세요. 다운로드 후 앱과 검은 실행창을 닫고 다시 엽니다. 공개 음성팩에는 승인한 98개와 청취 도구의 연결 정보가 포함됩니다. 개인 메모와 미선정 후보는 공유하지 않습니다. 기존 로컬 후보와 메모는 보존됩니다.

프로그램 폴더의 `scripts/open_short_radio_review.bat`를 실행하면 로컬 청취 페이지가 열립니다. 기본 주소는 `http://127.0.0.1:25486`입니다. 보유한 음원을 로컬에서 재생합니다.

사용자가 승인한 **20종·98개**를 적용합니다. 19종은 각각 5개, “앞에 다른 클래스 차량”은 원래 테이크 **2·4·5**의 3개입니다. 오른쪽 클리어는 **2·6·9·14·17**이며 17은 “오른쪽 클리어.”를 말하는 1초 녹음입니다. 같은 안내는 같은 짧은 문장을 말하고 발화·속도에 작은 차이를 둡니다.

처음 열면 현재 적용한 98개만 표시합니다. 각 행에서 강약 파형·재생 시간·발화 시간을 비교할 수 있습니다. 선별에는 음량과 전체 길이를 맞춘 파형·주파수 분포의 변화와 실제 발화 시간 차이를 사용했습니다. 앞뒤 무음과 긴 중간 무음은 선별의 이점으로 세지 않습니다. 미선정 후보는 **보관 후보까지 모두 보기**로 확인할 수 있습니다.

1. **듣기**로 비교하고 사용할 테이크의 **다음 적용**을 체크합니다. **기준 듣기**는 같은 안내의 기준 녹음과 비교합니다. 기준이 없는 안내는 버튼이 비활성화됩니다.
2. 원하지 않는 테이크는 **제외**로 표시하고 메모를 남깁니다. 선택·메모는 브라우저에 임시 저장되며 **선택·메모 내보내기**로 JSON 파일도 보관할 수 있습니다.
3. **선택 목록 저장**을 누르면 짧은 무전의 적용 목록에 저장됩니다. 안내 20종에 각각 하나 이상, 최대 5개여야 하며 앞 클래스는 원래 테이크 2·4·5를 유지합니다. 다른 시점의 적용 목록을 덮어쓰는 파일은 거절합니다. 기존 승인 표시는 계속 선택한 테이크에만 유지하며 새 선택을 자동 승인하지 않습니다.
4. 앱과 검은 실행창을 완전히 닫고 `실행.bat`으로 다시 엽니다. Fenrir·Charon의 **짧은 무전** 선택에만 적용됩니다. 기본 음성과 숫자·랩타임 음성은 기존 음원을 사용합니다.

**현재 적용 목록 선택**은 마지막 저장 목록을 불러옵니다. 이전 브라우저 초안의 적용 목록 확인값이 달라졌으면 마지막 저장 목록으로 시작합니다. `output/radio-variation-rebuild-20261114/index.html`을 파일로 열면 청취·선택·내보내기를 사용할 수 있고, 실제 저장은 위 로컬 서버 또는 `python scripts/review_short_radio.py --apply 선택파일.json`으로 수행합니다.

급유가 필요한 랩에는 피트 지시와 함께 추가 급유량을 읽습니다. 예를 들어 “이번 랩 끝나고 피트합니다. 급유는 40리터입니다.”는 지금 탱크의 총량이 아니라 추가할 양입니다. 가득 채우는 피트에서는 “급유 설정은 98리터입니다. 가득 채워야 합니다.”처럼 탱크 한도를 최대 추가 설정으로 구분하고 실제 주입은 탱크가 차면 멈춥니다. 리터 안내는 남은 연료 1.3랩 아래에서도 유지합니다. 준비된 급유 음성이 없으면 수치는 화면에 남기고 준비된 피트 지시를 먼저 전달하며 급유량을 전달했다고 처리하지 않습니다. 급유량·피트 지시의 개별 선택도 유지합니다. 새 음성은 제작하지 않았으며 현재 기본 캐시의 가득 급유 문장도 준비되지 않아 화면 안내와 피트 지시를 사용합니다.

급유는 이전의 유효한 랩 소비량을 지우지 않습니다. 같은 세션의 최근 5개 완전한 측정 중 최대 소비량을 사용합니다. 인시던트 점수 변화만으로 연료 측정을 버리지 않으며 깨끗한 랩의 절약 목표 평가는 따로 유지합니다. 피트·급유·불연속·재생이 섞인 랩은 제외하고 건조/젖음 전환이나 마지막 측정 후 1시간 경과 때 이력을 비웁니다. 마지막 랩에는 남은 완주 거리로 연료 경고를 판단하며 여유분 부족만으로 급유를 권하지 않습니다. 낮아졌다 돌아온 동일한 종료 예상 랩 수는 반복해서 “한 랩 늘었다”고 말하지 않습니다.

iRacing의 집계 순위는 긴 랩과 피트 이후 늦게 갱신될 수 있습니다. 최신 내 순위와 같은 프레임의 클래스 차량 진행 거리를 교차 확인하고 5초 유지된 현재 순위를 안내합니다. 접속이 끊겨 진행 거리가 -1로 초기화된 차량은 남아 있는 게임 집계 순서만 사용하며, 위치가 불명확한 활성 차량·오래된 프레임·서로 다른 순위는 확인 중으로 둡니다. 이 검사는 공식 결과 확정이 아닙니다. 피트 중에는 보류하며 집계 보정을 실제 추월·하락으로 표현하지 않습니다. 랩타임에는 순위를 붙이지 않고 직선·질문·독립 순위 안내가 같은 값을 사용합니다. 대기 중인 순위가 바뀌면 재생 전에 무효화하고 이미 전달한 동일 순위는 중복하지 않습니다. 앞뒤 차량도 진행 거리상 이웃인지 확인하며 LMU의 기존 순위 집계 방식과 경기 뒤 순위 그래프는 유지합니다.

## 2.4.0의 외부 로그 후속 개선 (2026-10-27)

퀄리 순위·격차 전체 문장이 준비된 음성 범위를 벗어나면 기존 순위 음성으로 안내합니다. 화면에는 원래 순위와 격차를 유지합니다. 일반 전체 문장은 1~40위·0.1~3.0초, 대체 순위 음성은 1~60위 범위입니다. 범위 판정은 실제로 읽는 소수 첫째 자리 표현을 따릅니다. 공동 기록처럼 격차가 0.0초로 표시되는 경우에도 순위만 읽습니다. 필요한 기본·선택 음성이 없거나 파일이 손상된 경우 이번 음성을 생략하며 자동 합성을 요청하지 않습니다. 퀄리 랩타임과 별도인 기존 순위 안내 시점·설정은 유지합니다.

재생 시작 전 오류는 같은 안내에서 총 3회까지만 시도합니다. 첫 실패 후 0.5초, 두 번째 실패 후 1초를 기다리고 유효시간·연결·주행 조건을 다시 확인합니다. 실패한 렌더 음성은 다시 받으며 새 안내와 안전 경고는 별도로 처리합니다. 세 번 실패하면 해당 안내를 종료합니다. 이미 시작한 안내의 기존 중단·재개 정책은 유지합니다. 실제 파일·코덱·장치 중 최초 오류 원인을 확정하는 기능은 아닙니다.

연결 대기 음성은 다른 음성이 재생 중이면 생략하고 화면 상태로 표시합니다. 차량에서 내리거나 연결이 끝나도 이미 시작한 경기 결과 문장은 끝까지 들을 수 있습니다. 생략한 연결 대기 음성을 새 세션에서 뒤늦게 재생하지 않습니다. 실제 좌우 차량 등 안전 경고는 여전히 먼저 말할 수 있으며, 사용자의 무전 끄기·게임 전환·장치 변경은 기존 동작을 따릅니다.

## 2.3.2의 로컬 진단 보완

음성 기록과 독립적으로 주행 연결 상태를 보관합니다. 별도 작업이 2초마다 상태를 확인하고 변화가 있거나 정상 수집 중 30초가 지나면 저장합니다. 최근 64개 주행과 각 주행의 최근 128개 상태만 유지하며 오래된 상태가 생략됐다는 개수도 남깁니다. 이 기록으로 실제 음성이 들렸는지나 정확한 연결 단절 순간까지 확정할 수는 없습니다.

로그 파일 받기에는 해당 주행의 상태 기록도 포함됩니다. 안내가 0건인 주행도 목록에서 찾을 수 있고 마지막 무전 이후의 기록을 확인할 수 있습니다. 무전의 취소·만료 등 전달 결과에는 접수 당시 최신 상태를 별도 표시하며, 이를 원래 안내 판단 순간의 상태로 해석하지 않습니다. 이전 세션의 늦은 결과에는 현재 세션의 주행값을 붙이지 않습니다.

기록은 로컬에 저장하며 마이크 내용·녹음·키·개인 설정을 추가 수집하지 않습니다. 기존 자동 보내기 동의와 전송 조건은 그대로입니다. 전송 한도가 부족하면 추가 상태 기록부터 제외하고, 용량이 남으면 기존 교통 자료를 보존하면서 원시 코너 묶음을 최대 3개까지 추가합니다.

테스트·연습에서는 레이스 출발 문구를 생략합니다. LMU 부분 기록은 트랙 전체 길이를 확인할 수 없다는 안내와 함께 코스 거리 비교를 보류합니다. 실측 조향이 없는 차량의 거동 판정 조건은 그대로 유지합니다.

## 2.5.5 무전 재생·보고·로그 보완 (2026-11-11)

음성의 브라우저 재생 시작이 연속 실패하면 성공하기 전까지 경고를 유지합니다. 두 번째 실패부터 오디오 효과 연결을 정리하고 30초 동안 효과·증폭 없이 원음을 시도합니다. 이 정리는 30초 안에 반복하지 않으며 출력장치 선택·볼륨·음소거·음성 속도·저장된 효과 설정은 바꾸지 않습니다. 계속 소리가 안 나면 “테스트 소리”를 눌러 브라우저 재생을 허용하고, 필요하면 앱과 검은 창을 완전히 닫고 다시 실행하세요. 실제 소리 출력 여부와 장치 문제의 원인은 이 진단만으로 확정하지 않습니다.

같은 자동 보고가 계속 유효하지만 전달되지 않은 경우 새 준비 기록을 반복 저장하지 않습니다. 현재 run에서 최근 20분·최대 8개 준비 결정을 재사용하며 매 요청마다 현재 상황·개별 안내 설정·운전 부하를 다시 확인합니다. 재생 실패는 5·10·20·30초 간격으로 재시도하고, 완료 확인 없이 전달 완료로 기록하지 않습니다. 정상 안전 중단의 재시도와 랩타임의 2초 시작 기한은 유지합니다.

재생 진단에는 브라우저의 준비/네트워크 상태 코드·일시정지 여부·오류 코드·효과 연결 여부·컨텍스트 상태·임시 원음 여부·제한된 연속 실패 횟수만 추가합니다. 장치 이름·ID·경로·계정은 수집하지 않습니다. 세션 로그를 줄인 뒤 작은 상태 진단이 다시 들어갈 공간이 생기면 선택 코너 상세보다 먼저 복원하며 유지 중인 교통 자료를 밀어내지 않습니다.
