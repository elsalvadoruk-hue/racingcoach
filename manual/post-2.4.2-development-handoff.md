# 2.4.3 공개 준비 인계

2026-10-28 기준. 작업 브랜치: `feature/post-2.4.2-development-20261028`.

공개 2.4.2 기준은 `756827e14c33b2e0a7caf36ac4e9b9a791511674`이며, 이후 제품 개발은 `3ef2e3ba39ab50108d4d270fdd8ea5a3a56a7f8a`에 모여 있다. 제품은 해당 개발본과 더트 오벌 제외 문서를 기준으로 2.4.3 공개를 준비한다. 실제 푸시·태그·릴리스 공개는 하지 않았다.

## 제품에 반영된 범위

- 포장 오벌 자동 구분, 지속 병렬·여러 대 겹침 안내, 안쪽/바깥쪽 표시와 기존 좌우 음성 대체.
- 오벌 경기·피트·대열 신호 수집, 사건 중심 로그 보존, 받은 로그 검수·기록 재생.
- 위트·절차 후보의 무음 관측과 반복 억제. 새 위트·코션·재시작 절차 발화는 비활성.
- 로그 자동 보내기 version4 동의문과 재동의 안내. 새 동의 전 자동 보내기를 중지하며 재동의 후 시작한 주행부터 보낸다.
- 더트 오벌 전용 기능은 현재·후속 개발 대상에서 제외한다. 새 음원 제작은 보류한다.

제품 사용 범위·검수 순서는 `manual/oval-next-patch.md`, `manual/oval-spotter-validation.md`, `manual/oval-log-review.md`를 따른다. 실제 오벌 주행·한국어 청취·다른 PC 검증은 남아 있다.

## 검증·배포 상태

배포 준비 시 전체 테스트·production build·두 게임의 화면 버전·패키지 내용·기존 업데이터 적용을 확인한다. 과거 검사 결과를 이번 버전의 새 검증 결과로 대체하지 않는다. 설치 안내와 공개 범위는 README·패치 노트·포장 오벌 문서를 기준으로 맞춘다.

이번 요청은 공개 준비다. main 병합·push·태그·릴리스 공개는 별도 실행 단계로 남긴다. 기존 개인 DB·설정·인증 파일과 실행 중인 앱/게임을 보존한다.
