# 코너 비교의 작은 조향·페달 표시

코너 비교 → 조작 비교에서 조향·브레이크·스로틀 그래프에 마우스를 올리세요. 포인터 오른쪽 아래에 작은 표시가 따라옵니다. 속도·기어·시간 차이 그래프에는 나타나지 않습니다.

- 조향: 지름 70px의 원 안에 공통 핸들 그림이 회전합니다. 차량에 따라 그림을 바꾸지 않습니다. 초록색 원호·점은 내 랩의 조향 위치, 흰 선은 비교 기준의 위치입니다. 가운데 숫자는 실제 조향각이며 한 바퀴를 넘는 각도도 유지합니다. 원 테두리는 처음 시안 두께의 1.2배인 1.8px입니다.
- 브레이크: 빨간 수직 바가 아래에서 위로 찹니다. 흰 가로선이 기준 입력입니다. B 옆 숫자는 내 입력(%)입니다.
- 스로틀: 초록 수직 바가 아래에서 위로 찹니다. 흰 가로선이 기준 입력입니다. T 옆 숫자는 내 입력(%)입니다.
- 페달 겹쳐 보기: 브레이크와 스로틀 두 바를 나란히 표시합니다. 각 바의 기준선은 해당 페달의 기준값을 사용합니다.

기존 그래프의 같은 거리에서 선택한 실측 표본을 사용합니다. 새 자료를 수집하거나 게임·설정에 쓰지 않습니다. 측정이 없는 값은 —이며 기준이 없으면 흰 선을 숨깁니다. 관측된 구간 밖의 값을 외삽하지 않습니다. LMU는 기록된 조향 입력(%)을 그대로 표시하며 실제 핸들 각도를 추정하지 않으므로 핸들 회전과 원의 각도 표시는 보류합니다.

표시는 그래프의 눈금·채널 이름·비교 포인트 위에는 나타나지 않으며, 드래그·그래프 이탈·스크롤·화면 크기 변경·초점 상실·Escape 때 숨겨집니다. 터치 조작 중에는 표시하지 않습니다. 화면 가장자리에서는 왼쪽 또는 위로 옮겨 잘리지 않게 합니다. 표시 자체는 클릭을 받지 않으므로 기존 드래그 확대·휠 이동을 그대로 사용할 수 있습니다.

로컬 변경 적용은 앱과 검은 실행 창을 완전히 닫고 실행.bat으로 다시 여세요. 아직 공개 업데이트에 포함되지 않았습니다.
