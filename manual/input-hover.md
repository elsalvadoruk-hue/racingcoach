# 코너 비교의 작은 조향·페달 표시

코너 비교 → 조작 비교에서 조향·브레이크·스로틀 그래프에 마우스를 올리세요. 포인터 오른쪽 아래에 작은 표시가 따라옵니다. 속도·기어·시간 차이 그래프에는 나타나지 않습니다.

- 조향: 지름 70px의 원 안에 공통 핸들 그림이 회전합니다. 차량에 따라 그림을 바꾸지 않습니다. 초록색 원호·점은 내 랩의 조향 위치, 흰 선은 비교 기준의 위치입니다. 가운데 숫자는 실제 조향각이며 한 바퀴를 넘는 각도도 유지합니다. 원 테두리는 처음 시안 두께의 1.2배인 1.8px입니다.
- 브레이크: 빨간 수직 바가 아래에서 위로 찹니다. 흰 가로선이 기준 입력입니다. B 옆 숫자는 내 입력(%)입니다.
- 스로틀: 초록 수직 바가 아래에서 위로 찹니다. 흰 가로선이 기준 입력입니다. T 옆 숫자는 내 입력(%)입니다.
- 페달 겹쳐 보기: 브레이크와 스로틀 두 바를 나란히 표시합니다. 각 바의 기준선은 해당 페달의 기준값을 사용합니다.

기존 그래프의 같은 거리에서 선택한 실측 표본을 사용합니다. 새 자료를 수집하거나 게임·설정에 쓰지 않습니다. 측정이 없는 값은 —이며 기준이 없으면 흰 선을 숨깁니다. 관측된 구간 밖의 값을 외삽하지 않습니다. LMU는 기록된 조향 입력(%)을 그대로 표시하며 실제 핸들 각도를 추정하지 않으므로 핸들 회전과 원의 각도 표시는 보류합니다.

표시는 그래프의 눈금·채널 이름·비교 포인트 위에는 나타나지 않으며, 드래그·그래프 이탈·스크롤·화면 크기 변경·초점 상실·Escape 때 숨겨집니다. 터치 조작 중에는 표시하지 않습니다. 화면 가장자리에서는 왼쪽 또는 위로 옮겨 잘리지 않게 합니다. 표시 자체는 클릭을 받지 않으므로 기존 드래그 확대·휠 이동을 그대로 사용할 수 있습니다.

2.5.4부터 포함됩니다. 기존 사용자는 앱의 업데이트를 적용하세요. 직접 소스를 사용한다면 앱과 검은 실행 창을 완전히 닫고 실행.bat으로 다시 여세요.

## GPS·고스트 지도 오른쪽 아래 비교창 (2.5.5)

코너 비교 → GPS·고스트의 오른쪽 아래에 작은 비교창이 표시됩니다. 상대 기준은 아래까지 채운 면, 내 랩은 그 위의 선입니다. 흰 현재 위치선은 그래프 오른쪽에서 20% 지점(왼쪽에서 80%)에 고정되며 주행할수록 그래프가 왼쪽으로 흐릅니다. 지도 위에 마우스를 옮기거나 고스트 시간 막대를 움직여 비교할 위치를 바꿀 수 있습니다. 기어를 제외한 설명·퍼센트·조향각 숫자를 숨겨 높이를 줄였습니다.

비교창 어디든 마우스 왼쪽 버튼으로 잡아 끌어 옮길 수 있습니다. 지도 영역과 화면에 보이는 영역 안으로 이동을 제한하며 창 크기나 스크롤이 바뀌면 다시 그 안에 맞춥니다. 보이는 지도 공간이 가로 300px 또는 세로 120px보다 작으면 비교창을 숨기고 넓어지면 다시 표시합니다. 비교창을 선택한 상태에서 방향키로 이동하거나 Home 키로 오른쪽 아래에 되돌릴 수도 있습니다.

배경 핸들 그림 없이 초록 원호는 내 조향, 흰 표시는 기준 조향을 나타냅니다. 가운데 큰 숫자는 내 기어입니다. 게임 오버레이처럼 같은 위치의 기준보다 낮으면 빨강, 같으면 흰색, 높으면 초록입니다. 기준이 없거나 중립·후진이면 회색이며 높고 낮음을 비교하지 않습니다. iRacing의 양수 조향은 왼쪽, 음수는 오른쪽이고 원호는 한 바퀴까지만 채웁니다.

두 입력은 같은 거리에서 비교합니다. 최근 표시 폭은 최대 한 랩의 8%이며 선택 구간이 더 짧으면 해당 폭을 사용합니다. 고스트 차 두 대는 같은 경과 시간으로 움직이므로 서로 다른 위치에 있을 수 있습니다. 종합 기준은 그래프 기준을 따르며 지도에 표시되는 대표 실제 랩과 구분됩니다. LMU는 실제 핸들 회전각을 추정하지 않으므로 조향 원호·흰 조향 표시는 보류합니다. 관측 범위 밖·결측 입력의 선은 끊기고 없는 기준 조향 표시는 숨깁니다. 기존 그래프 포인터 비교창은 계속 사용할 수 있습니다.

2.5.5에 포함됩니다. 앱의 업데이트를 적용하세요. 직접 소스를 사용한다면 앱과 검은 실행 창을 완전히 닫고 실행.bat으로 다시 여세요.
