# 포장 오벌 시험 기능과 로그 검수 안내

2026-10-29 앱 2.4.3 기준입니다. 2.4.2 Garage61 핫픽스를 포함하며 포장 오벌 기본 근접 안내를 시험 제공합니다. 공개 범위와 검증 상태는 [안내표](oval-next-patch.md)에 구분합니다. 사용자 본인이 오벌을 새로 배우거나 직접 경기에 출전해야 개발을 검증할 수 있는 구조는 아닙니다.

## 기존 화면에서 사용하는 방법

기존 스포터를 켜면 실제 연결된 iRacing 세션의 트랙 종류·정확한 레이아웃을 읽습니다. 포장 오벌로 확인되면 기존 상태 줄에 **포장 오벌**을 표시합니다. 별도 모드 선택이나 새 화면은 없습니다. 분석할 과거 파일을 고르거나 차량만 바꾼 것으로 오벌 모드를 결정하지 않습니다. 같은 시설의 로드 레이아웃은 따로 구분합니다.

- 기존 왼쪽 / 내 차량 / 오른쪽 세 칸, 경고색, 스포터 켜기·끄기, 반복 간격과 클리어 확인 시간을 사용합니다.
- 포장 오벌은 추월 중이거나 상대 속도 차가 큰 경우에도 0.4초 이상 확인된 겹침을 안내합니다. 진입 시간을 줄이지 않았습니다. 지속 병렬 주행은 설정한 2·3·5초마다 유지 안내를 합니다.
- 양쪽 차량·한쪽 두 대·한 대만 남음·클리어를 구분합니다. 출발 대열에서도 겹침을 안내합니다. 피트 안·차량 밖·리플레이·연결 끊김에는 기존처럼 겹침 상태를 지웁니다.
- 트랙 회전 방향이 확인되면 상태 줄은 **안쪽 / 바깥쪽**으로 표시합니다. 역방향 오벌은 좌우 대응을 뒤집습니다. 방향이 미확인이면 좌우를 유지합니다.
- 안쪽·바깥쪽 음성이 준비된 팩은 그 음성을 읽습니다. 과거 기본팩이나 선택한 커스텀팩에 해당 음성이 없으면 기존 좌우 음성으로 안내하며 실제 읽은 문구를 로그에 남깁니다. 새 문구를 자동 합성하지 않습니다. 기본 음성팩 2.4.3에는 안쪽·바깥쪽 14문장을 네 목소리로 제공합니다. 설정 → 업데이트 → 빠진 음성 받기로 받으세요.
- 더트·스키드패드·종류 미확인·LMU에는 이 포장 오벌 정책을 적용하지 않습니다. 더트 오벌은 후속 개발 대상에서도 제외합니다. 트랙 종류·식별 정보가 부족하면 기존 좌우 정책을 사용합니다.

코션 뒤 그린, 피트 개방, 정렬, 프리 패스와 웨이브 어라운드의 **새 절차 안내는 검증 대기**입니다. 현재는 신호를 기록하며 발화하지 않습니다. `PitsOpen`은 본인 피트 정차 허용 신호로 수집하며 피트 출구 통과 허용과 같다고 해석하지 않습니다. 실제 경기의 절차는 게임이 표시하는 지시를 따릅니다. 기존 깃발 안내와 F8 답변 우선순위는 유지합니다.

추가 개발본은 절차 신호의 변화·5초 간격 표본·후보·보류·취소·정상 그린 도달과 클라이언트 음성 점유 관측을 별도 `oval-procedures.json`에 남깁니다. 첫 출발과 재시작을 구분하고 중간 접속·시계 공백·역행 뒤에는 앞선 상태를 이어 추정하지 않습니다. SDK `PaceMode`의 비페이싱 값은 `4`이며 출발/재시작의 `0`~`3`에서는 위트 후보를 보류합니다.

## 오벌 사용자에게 전달할 요청문

2.4.3부터 적용합니다. 이전에 자동 보내기를 켰던 사용자는 업데이트 후 변경 내용과 재동의 창을 먼저 보게 됩니다. 다시 동의하기 전에는 전송하지 않습니다. 나중에 닫았다면 상단 **로그 재동의**에서 다시 확인합니다. 같은 동의문을 유지하는 이후 패치는 재동의를 요구하지 않습니다.

> 한국어 스포터의 포장 오벌 시험 기능을 검수하고 있습니다. 개발본을 사용하시는 오벌 주행자분은 **세션 로그 자동 보내기**를 켜고 평소처럼 연습이나 경기를 해 주세요.
>
> 화면 맨 위의 **로그 보내기** 또는 **세션 로그 자동 보내기**를 누르고 안내 내용을 확인해 동의하면 됩니다. 이전에 켰더라도 이번 개발본의 바뀐 안내에 한 번 다시 동의해 주세요. 오벌 여부·트랙·차량은 받은 로그에서 구분하므로 따로 파일을 받거나 보내실 필요가 없습니다. 2분 이상 기록된 포장 오벌 주행은 안내가 없었어도 검수에 도움이 됩니다.
>
> 이상한 안내가 있었다면 몇 랩쯤인지와 상황을 짧게 알려 주시면 도움이 됩니다. 설명이나 영상은 선택이며, 문제가 없던 주행도 환영합니다. 위험한 상황을 일부러 만들 필요는 없습니다.
>
> 이번 버전은 주로 겹침·유지·클리어를 검수합니다. 코션·재시작 절차의 새 안내는 아직 켜지 않았습니다. 현재 기본 음성팩은 좌우로 말하며 화면은 방향이 확인되면 안쪽·바깥쪽으로 표시합니다. 자동 보내기에는 마이크 질문과 답변을 넣지 않습니다. 자동 보내기는 iRacing과 LMU에 함께 적용되며 언제든 끌 수 있습니다.

이 문서는 전달용 초안입니다. 앱이나 개발 도구가 다른 사용자에게 메시지를 보내지는 않습니다.

자동 보내기는 마지막 기록 뒤 10분 이상 지나고 해당 주행이 현재 세션이 아닐 때 확인합니다. 앱을 바로 종료했다면 다음 실행 때 보냅니다. 동의하기 전에 시작한 주행은 보내지 않습니다. 전송 실패는 기존 재시도·하루 전송 한도를 따릅니다. 별도 ZIP은 전송 실패나 추가 세부 자료가 필요한 경우에만 선택적으로 요청합니다.

## 자동으로 받은 로그의 구분과 용량 제한

`manifest.json`의 `spotter.profile`로 `ASPHALT_OVAL` / `DIRT_OVAL` / `ROAD` / `UNKNOWN`을 구분합니다. 이 항목은 추가 자료가 용량 때문에 빠져도 기본 로그에 남습니다. `scripts/read_coach_log.py`도 분류를 표시합니다. 분류 자료가 없는 과거 로그와 트랙 미확인은 오벌로 추측하지 않습니다.

포장 오벌은 1.4MB 전송 한도를 넘으면 주행 측정값 요약부터 제외하고, 주변 차량 자료를 최대 6개 창·창당 최대 200행으로 줄입니다. 시작·끝과 비교 구간을 확보한 뒤 양쪽 차량·긴 병렬·클리어·피트/대열 신호 변화·재생 실패/중단 전후를 우선 고릅니다. 선택된 원본 행의 시간·누락·0/false를 보존하며 공백·시계 역행을 건너지 않습니다. 압축 자료도 최대 160KB로 제한하며 필요하면 행 수를 더 줄입니다. `traffic` 헤더의 `export_selection`에 원본/선택/생략 행 수와 사건 수, 각 구간의 원본 행 범위·시간을 기록합니다. 사건이 많으면 일부는 생략됩니다. 전체 차량 순위 자료는 축소본에 넣지 않습니다. 축소본도 공간이 부족하면 주변 차량 자료를 제외하고 진단 기록을 우선 남깁니다. 기본 로그 자체가 너무 크면 기존처럼 전송 실패 이유를 표시합니다.

일부 구간이 빠진 자동 로그를 전체 주행 재현이나 오류가 없었다는 증거로 사용하지 않습니다. 장면의 정확한 대응·실제 청취는 별도 확인하며, 상세 자료가 필요할 때만 해당 사용자에게 선택적으로 추가 요청합니다.

받은 ZIP/폴더는 [자동 검수·기록 재생 도구](oval-log-review.md)로 분류하고 의심 구간을 찾을 수 있습니다. 실제 무전 이력을 함께 보며, 위트 후보는 발화 조건 부족으로 모두 보류합니다.

## 받으면 확인할 항목

| 검수 대상 | 필요한 관측 |
| --- | --- |
| 자동 판정 | 포장 오벌과 같은 시설 로드 레이아웃, 차량이 다른 경우, 방향 누락·역방향 |
| 근접 안내 | 추월 중 누락, 양쪽/한쪽 두 대 전환, 한 대만 남은 상태, 긴 병렬 반복 |
| 클리어 | 실제 겹침이 남아 있는데 비었다고 말하는지, 짧은 신호 흔들림, 피트·재접속 뒤 잘못된 클리어 |
| 재생 | 실제 들린 문구·지연·반복 피로도, 기존 좌우 음성 대체, F8·다른 무전과의 순서 |
| 향후 경기 절차 | 코션·대열·피트 지시가 바뀐 시각과 수집한 원시 신호의 대응. 배정 신호만으로 추월 허용을 추측하지 않음 |

오벌 연습·경기의 주변 차량 로그는 최대 10Hz로 기록합니다. 상태 줄이 포장 오벌이어도 트랙 길이·본인 위치가 없으면 주변 차량 기록은 생기지 않을 수 있습니다. 무전이 없던 주행도 독립 세션 진단으로 식별하며 내보내기 목록과 ZIP에 넣습니다. 기록은 기존 파일 수·큐·저장 제한을 따르므로 모든 프레임의 완전한 보존을 보장하지 않습니다. 과부하로 빠진 행 수와 기록 실패 여부는 세션 진단에 남기며, 실제 30Hz 음성 판단과 10Hz 로그의 시간 차도 검토합니다.

## 개발 검증과 실주행 검증의 구분

합성 검사는 자동 판정, 좌우·방향 대응, 상태 전환, 오래된 안내 폐기, 기존 음성 대체, 외부 합성 미호출, 연습 로그와 ZIP 포장 복원 등을 검증합니다. 실제 게임 신호의 의미·타이밍과 한국어 청취 품질은 오벌 사용자 자료로 별도 확인해야 합니다. 현재 확보한 외부 197 ZIP 중 확인된 오벌은 0이며 트랙 미확인 5개는 오벌/로드로 확정하지 않았습니다. 정확도·사고 감소·모든 오벌 지원 완료로 표현하지 않습니다.

구현·측정·검수 근거는 `logs/oval-development-20261028/`, 앞선 규정 조사와 후속 기획은 [오벌 스포터 기획안](oval-spotter-plan-20261028.md)을 참고합니다.
